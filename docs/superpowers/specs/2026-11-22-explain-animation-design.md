## 1. 何を足すか

盤を開くと、先生が話しながら図を 1 手ずつ描いていく。終わると、今までどおり自分で動かせる（ユーザー決定: 「説明のあとに動かす」）。
理科クエストの解説カードとのちがいは、盤いっぱいに、言葉と一緒に 1 手ずつ描き進めること。描く線は、すべて計算エンジン（`scene.trace`）が法則から求めたものだけを使う。台本が線の位置を決めることはない。

## 2. 決めたこと（利用者から見た動き）

### 2.1 流れ

```
盤を開く
  └ はじめの画面: 「だれに教えてもらう？」（6 体から 1 体）
       ├「🔊 音声ありで見る」 ┐
       ├「音声なしで見る」     ├→ 説明（1 手ずつ自動で進む）→ 自分で動かす
       └「説明をとばして、すぐ動かす」────────────────→ 自分で動かす
自分で動かしている間: 「▶ もう一度、説明を見る」で、はじめの画面へ戻る
```

- はじめの画面を毎回出す理由: iPad は、画面を押してからでないと音を出せない。教室で音を出したくないときにも、ここで選べる（Claude の判断）。
- 前にえらんだ先生・音声のあり・なし・速さは、端末に覚えてあり、はじめからその状態になっている。

### 2.2 先生（ユーザー決定: 生徒が自由にえらべる。声は男性と女性を混ぜる。割り当ては Claude Code に一任）

- 6 体（まる先生・しずく博士・ぷにカプセル・もくもく先生・キューブ先生・まめ博士）。はじめにえらばれているのは、その単元の担当（「光の世界」はキューブ先生）。
- 理科の中身は 1 つで、先生ごとに変わるのは言い回しと声だけ。用語（「」の中）・手の数・描くものは同じ。
- 説明の途中の「先生をかえる」で、はじめの画面へ戻る（かえると、説明は 1 手目からやり直す）。
- 声は VOICEVOX Nemo であらかじめ作った音声ファイル（1 手につき 1 つ）。割り当てと作り方は `docs/characters-and-scripts.md` 4 章。

### 2.3 説明の進み方

- 今の言葉は、盤のすぐ上の吹き出し（先生の絵つき）に出す。横のパネルには「ここまでの説明」を番号つきで残す。
- 1 手は「描く → 読む間」。音声ありのときは、声の長さの 8 割で描き終わるように描く速さを引きのばし、**声の終わりと描き終わりの両方**を待ってから、間（1.5 秒）を置いて次の手へ進む。
- 描き方: 線は始点から終点へのびる。文字は 1 文字ずつ現れる。角の弧は広がる。部品（光源・物体など）は、ふわっと現れる。描いている先に、ペンの印を出す。
- 操作の帯: 「◀ もどる」「⏸ 止める / ▶ 再生」「次へ ▶」、進み具合の印、「速さ − 1 倍 ＋」、「🔊 音声オン / 🔇 音声オフ」、「先生をかえる」、「とばして自分で動かす」。
- 「次へ」: 描いている途中なら、その手を描き終えた形にする。描き終わっていれば、次の手へ。最後の手なら、自分で動かす状態へ。
- 「もどる」: 1 つ前の手を、はじめから。1 手目では押せない。
- 「止める」: 描く動きと声を止める。「再生」で続きから。
- 最後の手まで終わると、操作の帯が消え、つまみが出て、パネルが「ためしてみよう」に変わる。吹き出しには、最後の言葉を残す。

### 2.4 速さ（ユーザー決定）

- 0.5 倍から 2 倍まで、0.25 きざみ（0.5・0.75・1・1.25・1.5・1.75・2）。はじめは 1 倍。「−」「＋」で変え、端では押せなくなる。
- 声の高さは変えず、速さだけを変える。再生中でもすぐ変わる。描く速さと、手と手の間も同じ倍率で変わる（音声なしのときも）。

### 2.5 音声

- 音声ありをえらぶと、その盤・その先生の音声（7〜9 個、約 300KB）を読みこむ。1 手目の音声の準備ができるまで、「音声ありで見る」は「準備中…」で押せない。
- 一度読みこんだ音声は端末に保存し、次からは通信なしで再生できる。まだ開いていない盤・先生の音声は、通信がないと読みこめない。
- 音声を読みこめない・再生を断られたときは、**だまって消さず**、黄色の帯で知らせて、文字だけで続ける（「音声を読みこめませんでした。文字だけで続けます。」など）。
- クレジット: ホームの下と、はじめの画面に「音声: VOICEVOX Nemo（女声 2・3・4、男声 1・2・3）」と出す。README にも書く。

### 2.6 端末に覚えること

- えらんだ先生、音声のあり・なし、速さの 3 つだけ（localStorage）。学習の記録は入れない。
- これまで「端末に何も保存しない」としていた決まりを、この 3 つに限って変える（ユーザーに報告済み）。

### 2.7 動きを減らす設定の端末

`prefers-reduced-motion` の端末では、描く動きを省き、1 手ずつ完成した形で出す。声と手の進み方は同じ。

## 3. 端の場合（決めたこと）

| 場合 | 扱い | 画面での見せ方 |
|---|---|---|
| 覚えてある先生が知らない id、速さが 7 つの値以外・数字の文字列・とても大きい値、音声が真偽値でない | その項目だけ、はじめの値（担当の先生・1 倍・音声なし）にする。自動で近い値に直さない | はじめの値で出る |
| 覚えてある値が壊れている（JSON として読めない・配列・null） | 全部はじめの値にする | 同上 |
| 端末に保存できない（プライベートブラウズなど） | 覚えずに、その場だけで使う | 何も出さない（学習には影響しない） |
| 速さを端（0.5・2）からさらに変えようとする | 変えない | ボタンが押せない |
| 音声ファイルを読みこめない（通信なしで未保存、ファイルがない） | 音声をオフにして、文字だけで続ける | 黄色の帯「音声を読みこめませんでした。文字だけで続けます。」 |
| 端末が再生を断る | 同上 | 黄色の帯「この画面では音を出せませんでした。文字だけで続けます。」 |
| 声の終わりの合図が来ない | 声の長さ ÷ 速さ ＋ 4 秒で先へ進む | 止まらない |
| 説明の途中で、別のタブへ移る・画面を消す | 説明と声を止める。戻ったら「再生」で続きから | 「▶ 再生」になっている |
| 説明の途中で「← ボード一覧」・ブラウザの戻る | 声を止めて、ホームへ | 声が残らない |
| 説明の途中で、盤にさわる | 動かせない（つまみは、最後の手まで出さない） | 何も起きない |
| 「次へ」「もどる」をすばやく続けて押す | 前の声を止め、古い「終わりの合図」は無視する。最後に押した手だけが進む | 声が重ならない |
| 説明の途中で画面の幅が変わる（回転など） | 今の手の、今の進み具合のまま描き直す | 続きから |
| 台本の `draw` に、盤の計算結果にないものが書いてある | テストで止める（公開前に見つける）。画面では、その部分を描かずに進む | — |
| 不正なシーン（「この図は表示できません」） | 説明は始めない。はじめの画面も出さない | 今までどおりの文 |
| 屈折の盤で、説明のあとに向きや物質を切り替えて「もう一度、説明を見る」 | はじめの配置（空気 → 水）に戻してから説明する | はじめの配置で始まる |
| 音声ありで、音声ファイルの長さが 0・不明 | 文字数から決めた時間（1 文字 0.18 秒 ＋ 1 秒）を、その手の長さとして使う | 止まらない |

### 4.2 台本の `draw` と、盤の計算結果の対応

| `draw` | 描くもの |
|---|---|
| `el:<type>` | その type の部品の形と、その名前（つまみの文字、または marks の同じ名前の文字）。`el:boundary` は境目の線・物質の色・「空気」「水」、`el:lens` はレンズの形 |
| `normal` | 法線の線と「法線」 |
| `axis` | 光軸の線と「光軸」 |
| `focus` | 焦点の点と「焦点」（盤の中にあるもの全部） |
| `shadow` | スクリーンの影の部分と「影」 |
| `image` / `image-label` | 像の矢印 / 像の名前（「像」「実像」「虚像」） |
| `ray:<role>` | その role の光線（複数あれば同時に）。矢印は線が描き終わってから出す |
| `angle:in` / `angle:out` | 角の弧・名前・数字 |
| `point:<相手>` | 何も描き足さず、相手（部品の type、`controls`、`focus`）を指す印（ふちが光る輪）を出す |
| `handles` / `controls` | つまみ / 切り替えを出す（ここから自分で動かせる） |

`scene.trace` が光線に付ける `role`:

| 盤 | role |
|---|---|
| straight | `edge`（2 本） |
| reflect | `incident`、`reflected` |
| mirror-image | `to-mirror`（2 本）、`to-eye`（2 本）、`extension`（破線 2 本） |
| refract | `incident`、`refracted`（全反射のときはない）、`reflected` |
| lens | `to-lens`（3 本）、`to-focus`（3 本。レンズから焦点まで）、`beyond-focus`（3 本。焦点から先） |
| lens-image | `ray1`・`ray2`・`ray3`（それぞれ、物体からレンズまでと、レンズから先の 2 本）、`extension`（虚像のときの破線） |

`role` を足しても、光線の位置・数・`measures` は変えない（凸レンズの盤だけ、1 本だった「レンズから先」の線が、焦点で 2 本に分かれる。つないだ形は同じ）。

### 4.3 時間割

- 1 手の中の `draw` は、書いた順に描く。1 つあたりの描く時間（暫定、`config.js`）: 部品 350ms、線 800ms（複数本は同時）、文字 1 文字 90ms（最短 300ms）、弧 600ms、印 600ms。
- 音声ありのとき: `引きのばし = max(1, 声の長さ × 0.8 ÷ その手の描く時間の合計)`。
- 1 手の長さ = `max(描く時間 × 引きのばし, 声の長さ) ÷ 速さ ＋ 間（1.5 秒 ÷ 速さ）`。
- 時間割と「時刻 t に見せるもの」は `js/explain.js` が計算する（画面なしでテストできる）。

## 5. テスト

- `scripts`: 6 つの盤 × 6 体がそろう。先生ごとの文に、基本の台本（E）と同じ用語（「」）が同じ数だけある。1 つの文は 75 文字以内。`draw` に書けるのは 4.2 の表のものだけ。
- `explain`: 6 つの盤のはじめの配置で、台本の `draw` がすべて、計算結果のどれかに当たる（`ray:<role>` の role が実際にある、など）。最後の手に `handles` がある。時間割（音声あり・なし、速さ 0.5・1・2、声の長さ 0・不明）。「時刻 t に見せるもの」が、t を進めると増えるだけで減らない。「もどる」「次へ」の行き先。
- `scene`: role が 4.2 の表のとおり付く。role を足しても、光線の位置・数（凸レンズの分け方を除く）・`measures` が前と同じ。
- `prefs`: 3 章の表の各行。
- `voice`: 速さの 7 つの値と端。再生を断られたとき・読みこめないときの知らせ。古い「終わりの合図」を無視する。止める → 再生。
- `voice-light`（音声の一覧）: 台本の全部の手に音声があり、ファイルが実在し、長さが 0 より大きい。
- `offline`: 新しい JS が `PRECACHE` にある。音声は `PRECACHE` に入れない（別のキャッシュ）。
- 画面はブラウザで確かめる（6 つの盤、6 体、速さ、音声あり・なし、iPad の幅）。声の聞こえ方は、公開版でユーザーが確かめる。

## 6. 公開について

- `sw.js` の `VERSION` を上げる。
