# 中学生向けAI理科学習アプリ 要件定義書 v0.1

## 1. プロジェクト概要

AhaBoardのように、AIがホワイトボードに図やグラフを描きながら、生徒に個別指導する学習アプリ。

授業中の個別学習・一斉授業・家庭学習に対応する。

初期試作品は中学1年理科「光の世界」の全範囲とする。

## 2. ターゲットユーザー

- 生徒：中学生（学校では1人1台のiPadを使用）
- 教師：初期版では1人
- 最大同時利用人数：30〜40人
- 対応端末：iPad・スマートフォン・パソコン

## 3. アプリのゴール

### WHO（誰に）

授業や家庭学習で理解につまずく中学生。

### WHAT（何を）

AIによる対話、視覚的な解説、操作できる図、理解度に応じた個別学習を提供する。

### HOW（どうなってもらいたいか）

生徒が自分から質問・実験・確認を繰り返し、理解を深められるようにする。

## 4. 主要機能

### 必須機能（試作品の対象）

**AI学習機能**

- 教科・単元選択、文字・音声・写真による質問
- 文字と音声による解説（音声オン・オフ可能）
- 理解状況に応じたヒントや詳しい説明
- 会話による理解確認と確認問題
- 自由学習・AIおまかせ学習の切り替え

**ホワイトボード**

- 確認済みの図を使った解説
- 科学的ルールに従った新しい図の生成
- 生徒が光源・鏡・レンズなどを操作できる
- 光の直進・反射・屈折・全反射・凸レンズ・実像と虚像に対応

**授業モード**

- 先生操作モード
- 先生と生徒の画面連動モード
- 生徒の自由学習モード

**先生用機能**

- 生徒の専用アカウントを一括発行
- パスワードの再設定
- 学習状況・理解度・苦手分野の要約表示
- 手動教材作成・AI教材自動作成
- 単元名または先生の資料から教材を生成
- 教材の下書き・プレビュー・修正・公開

**生徒用機能**

- 専用IDによるログイン
- 自分の学習履歴の確認
- 卒業前の学習履歴PDF保存

**オフライン対応**

- 単元を開いたときに教材を自動保存
- 通信がなくても確認済み教材・問題・操作できる図を利用
- 再接続後に学習履歴を自動同期
- AIが使えない場合も保存済み教材で学習を継続

### 追加予定機能

- 中学理科のほかの単元・学年への拡張
- 複数教師による管理・教材共有
- より高度な個別学習の最適化

## 5. 技術仕様・運用条件

- ブラウザで利用できるWebアプリ
- 最大30〜40人の同時利用を想定
- 運用費0円を目標
- 試作品ではAI利用回数の制限を許容
- 完成版ではAI利用回数無制限を目標
- 無料運用の実現可能性は別途検証が必要

### データ管理

- 生徒の本名は登録しない
- クラス・出席番号などのIDで管理
- 先生は生徒のAI会話履歴を閲覧しない
- 撮影した画像は読み取り後に削除する
- 学習履歴は卒業まで保存し、卒業後に削除する
- 進級時も同一生徒の学習履歴を引き継ぐ

## 6. UI/UX方針

- 中学生が直感的に操作できる画面
- iPadのタッチ操作を優先
- スマートフォンやパソコンの画面サイズにも対応
- AIホワイトボードを中心に配置
- 学習中でも自由学習とAIおまかせ学習を切り替え可能
- 音声を使えない教室でも文字だけで学習可能
- 通信やAIの利用状況を分かりやすく表示
