2. 盤「ばねののび」（force-spring）

おもり 1 個は 20 g で、ばねを引く力は 0.2 N（100 g の物体にはたらく重力を 1 N とする）。ばね A は 0.2 N で 1.0 cm、ばね B は 0.2 N で 2.0 cm のびる。おもりは 0〜5 個。はじめは ばね A・3 個（0.6 N、3.0 cm）。右のグラフに、今までにためした点が残り、原点を通る直線になる（フックの法則）。

3. 盤「力の表し方」（force-arrow）

力の 3 つの要素（作用点・向き・大きさ）を矢印で表す。矢印の先の白い丸を引くと、長さ（1〜5 N、1 目もり ＝ 1 N）と向き（上・下・左・右）が変わる。はじめは 右向き 3 N。

  • □上向きに 2 N の力を、矢印で表そう。
  • □左向きに 4 N の力を、矢印で表そう。

4. 盤「力のつり合い」（force-balance）

厚紙を左右から引く。左右の力はそれぞれ 1〜5 N。切り替えで、2 つの力を「一直線上」か「ずれている」にできる。つり合うのは、大きさが等しく・向きが反対で・一直線上にあるときだけ。それ以外は「右へ動く」「左へ動く」「回って動く」と出す。はじめは 左 3 N・右 3 N・一直線上（つり合っている）。

ためしてみよう

  • □左右の力を両方 5 N にして、つり合わせてみよう。
  • □右の力を左の力より大きくして、厚紙が右へ動くのを見よう。
  • □大きさが同じでも、力をずらすとつり合わないことをたしかめよう。
