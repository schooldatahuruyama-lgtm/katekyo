ひかりボード 単元の見本

中学 3 年分の理科、15 単元の一覧です。見本は動かない絵で、数値や文は案です。「見本を開く」で、盤の絵・盤の下の値・ためしてみよう・決めたこと（案）が見られます。

  • 見本でよい単元は、単元の名前と「OK」を伝えてください。OK の出た単元から、台本・声・実装・公開へ進めます。
  • 盤の入れかえや数値の変更は、単元と盤の名前で教えてください。
  • 理科として確かめてほしい点は、各見本の最後の「決めたこと（案）」にまとめてあります。
