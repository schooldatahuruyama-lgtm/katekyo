2. 盤「光合成」（bio-photosynthesis）

植物は、光を受けて、葉の緑色の部分（葉緑体がある所）で、水と二酸化炭素からデンプンなどの養分をつくり、酸素を出す（光合成）。切り替えは 3 つ: 光（あり・なし）、二酸化炭素（あり・なし）、しらべる所（緑色の部分・ふ（白い所））。3 つの条件がそろったときだけ「光合成が起こる」となり、デンプンができて酸素が出る。1 つでも欠けると「光合成は起こらない」となり、欠けた条件に × が付き、出入りの矢印が消える。水は、いつも根から届いているものとする。はじめは 光あり・二酸化炭素あり・緑色の部分（光合成が起こる）。

3. 盤「消化と吸収」（bio-digestion）

食べ物の栄養分は、消化液にふくまれる消化酵素のはたらきで、吸収されやすい小さな物質に分解される。栄養分を切り替えると、口 → 胃 → 小腸の順に、はたらく消化液と消化酵素、できる物質、吸収される所が変わる（はたらかない所は「はたらかない」と出る）。デンプン: だ液（アミラーゼ）・すい液（アミラーゼ）・小腸のかべの消化酵素 → ブドウ糖 → 柔毛の毛細血管。タンパク質: 胃液（ペプシン）・すい液（トリプシン）・小腸のかべの消化酵素 → アミノ酸 → 柔毛の毛細血管。脂肪: 胆汁（消化酵素はふくまないが、脂肪の分解を助ける）・すい液（リパーゼ）→ 脂肪酸とモノグリセリド → 柔毛で吸収されたあと再び脂肪になり、リンパ管に入る。すい液と胆汁は、小腸のはじめの部分に出る。はじめは デンプン。右の丸のモデルは、つながりが切れていくようすを表す（丸の数は見本用）。

4. 盤「血液の循環」（bio-circulation）

血液は、心臓から出て肺をめぐる肺循環と、心臓から出て全身をめぐる体循環で、体の中をめぐる。肺循環: 右心室 → 肺動脈 → 肺 → 肺静脈 → 左心房。体循環: 左心室 → 大動脈 → 全身 → 大静脈 → 右心房。酸素が多い動脈血は赤い実線、酸素が少ない静脈血は青い破線で表す（肺動脈には静脈血、肺静脈には動脈血が流れる）。切り替えで選んだ循環が太い線になり、動脈血・静脈血の文字が出る。選んでいない循環は細くうすい線になる。血管が交わらないように描いた模式図で、本当の形とはちがう。はじめは 体循環。

5. 盤「刺激と反応」（bio-reflex）

刺激の信号は、感覚器官 → 感覚神経 → せきずい → 脳と伝わり、脳の命令が せきずい → 運動神経 → 筋肉と伝わって反応が起こる（意識して起こる反応。通る所は 7 つ）。熱いものにふれて思わず手を引っこめるときは、信号がせきずいから直接、運動神経に伝わる（反射。通る所は 5 つ）。脳を通らないので、刺激を受けてから反応するまでの時間が短い。切り替えで、選んだ反応の経路がだいだい色の太い線と ①〜 の番号で順に示される。意識して起こる反応の例は「手が冷たいと感じて、手をこすり合わせる」。反射でも、信号は少しおくれて脳にも伝わり、あとから「熱い」と感じる（これは説明の文で伝える）。はじめは 反射。
