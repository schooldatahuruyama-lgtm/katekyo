# 音声ファイルについて

このフォルダの音声（`light/<盤>/<先生>/<番号>.mp3`）は、**VOICEVOX Nemo** で作った合成音声です。

- クレジット: **VOICEVOX Nemo（女声 2・女声 3・女声 4・男声 1・男声 2・男声 3）**
- 利用規約: https://voicevox.hiroshiba.jp/nemo/term/ （2026-11-22 に確認）
- このリポジトリのプログラムの扱いと、音声の扱いは別です。音声を使うときは、上の利用規約に従ってください。
  - クレジットを表記すること。
  - 機械学習に使わないこと。
  - 著作の情報を偽らないこと。VOICEVOX や音声の提供者の信用・品位を損なう使い方をしないこと。

## 作り方

台本（`content/scripts-light.js`）から、`tools/make-voice.mjs` で作ります。手で編集しません。

1. VOICEVOX Nemo のエンジンを、このパソコンの中で動かす（`run.exe --host 127.0.0.1 --port 50121`）。
2. `node tools/make-voice.mjs --ffmpeg <ffmpeg.exe のパス>` を実行する。文・声・速さが前と同じ音声は作り直しません。
3. 最後に出る「読みの点検」を見る。「読みを確かめる所」が出たら、`content/scripts-light.js` の `READING_RULES` に読み方を足して、もう一度実行する。
4. `light/manifest.json`（作った記録。読みがな入り）と `content/voice-light.js`（アプリが読む一覧）が一緒に更新されます。

形式は MP3・モノラル・24kHz・64kbps。音量はそろえてあります。声によって話す速さがちがうので、同じ文を読む時間が同じになるように、声ごとに速さを調整しています（`tools/make-voice.mjs` の `VOICES`）。
