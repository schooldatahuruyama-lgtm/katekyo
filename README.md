# ひかりボード

中学 1 年「光の世界」を、光源・鏡・レンズなどを動かして確かめるアプリです。
HTML・CSS・JavaScript だけで動き、外部ライブラリや外部フォントは使いません。

## 開き方

手元で試すときは、このフォルダの `index.html` をブラウザで開きます。
`file://` でも盤は動きますが、Service Worker は登録しません。

オフライン対応を確かめるときは、このフォルダを静的 Web サーバーで配信してください。
HTTPS の公開先、または `http://localhost` で開きます。パッケージの追加やビルドは不要です。
Python が既に入っている環境なら、このフォルダで次のコマンドを実行できます。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

その場合はブラウザで `http://localhost:8000/` を開きます。
サーバーは `Ctrl+C` で終了します。Python のない環境では、既存の静的サーバーや HTTPS の公開先を使ってください。

## 6 種類の盤

| 盤 | 動かせるもの・確かめられること | 直接開く指定 |
|---|---|---|
| 直進 | 光源とついたて、スクリーンの影 | `?board=straight` |
| 反射 | 光源と鏡の傾き、入射角と反射角 | `?board=reflect` |
| 鏡の像 | 物体と見る人、鏡の奥の像 | `?board=mirror-image` |
| 屈折・全反射 | 光源、光の進む向き、水・ガラスの切り替え | `?board=refract` |
| 凸レンズ | 光源の高さと焦点距離、平行な光が集まる位置 | `?board=lens` |
| 実像と虚像 | 物体とスクリーン、像の位置・大きさ・向き | `?board=lens-image` |

丸いつまみを指やマウスで動かします。キーボードでは Tab でつまみを選び、矢印キーで動かせます。
キーボードで選んだつまみにだけ、青い丸の枠を表示します。
2 本同時にさわっても、つかんでいる最初の指だけを追います。

「ためしてみよう」は条件を満たすと ✓ と「できた！」が付きます。
「はじめの配置にもどす」は配置と切り替えを戻し、✓ は残します。
盤を開き直したりページを再読み込みしたりすると、配置と ✓ は初期状態に戻ります。
盤の下に出す数は角度（°）と倍率（倍）です。距離・高さの座標値は出しません。
先生向けの案内文・課題・盤の下の表示の一覧は [docs/reports/boards.md](docs/reports/boards.md) にあります。

レンズを通らない代表光線は、延長の破線も含めて省きます。像の位置はうすいレンズの式で求めます。
角度の数字は優先して表示し、重なる名前は移動するか省きます。
不正な配置では盤に「この図は表示できません」と最初の理由を出し、値・切り替え・課題の判定を止めます。
「← ボード一覧」と「はじめの配置にもどす」は使えます。

## オフラインと更新

対応するブラウザで一度オンラインのまま開き、Service Worker の準備が終わると、6 種類すべてをオフラインで開けます。
盤を指定した URL でも、キャッシュ済みの `index.html` を開きます。
通信状態は上の帯に表示します。オフライン準備の失敗はコンソールに警告を出し、画面の利用を続けます。
ブラウザがサイトのデータを消した場合は、もう一度オンラインで開く必要があります。

アプリのファイルを更新するときは、必ず `sw.js` の **`VERSION` を上げてください**。
形式は `YYYY-MM-DD-連番` です。読み込むファイルを増やしたら `PRECACHE` にも追加します。
新しい版の準備が完了すると、`hikari-board-` で始まる古いキャッシュを削除します。
更新後の画面は再読み込みして確かめてください。

保存するのはアプリのファイルのキャッシュだけです。
localStorage・IndexedDB・Cookie に配置や個人情報を保存しません。

## 確認

Node.js が入っている環境で、次を実行します。

```powershell
npm test
```

計算エンジン、レンズの範囲と光線、垂直入射付近の角度数字、文字の重なり回避、表示サイズと線幅、矢印の位置と大きさ、倍率の読み出し、座標変換、不正な配置からの復帰、イベントの連携、配布ファイルとキャッシュを確認します。
DOM の代替環境を使ったテストは、実ブラウザの描画・タッチ・Service Worker の動作を保証するものではありません。

実ブラウザでは、パソコン幅・768px・375px で 6 盤を開き、文字の重なり、指の操作、戻る・進む、オフラインでの再読み込みを確認してください。
実機では、盤の外まで引く、2 本目の指を置く、操作を中断する場合も確認します。

不正なシーンの表示を開発用に確かめる場合は、盤を開いてブラウザの開発者コンソールで次を実行します。
元のファイルは変更しません。

```javascript
var originalGet = Hikari.boards.get;
Hikari.boards.get = id => {
  const board = originalGet(id);
  if (board) board.scene.elements = {};
  return board;
};
window.dispatchEvent(new PopStateEvent('popstate'));
```

「この図は表示できません」と理由が出ること、値と切り替えが消えること、「← ボード一覧」が使えることを確かめます。
次で元に戻し、「はじめの配置にもどす」を押してください（再読み込みでも元に戻ります）。

```javascript
Hikari.boards.get = originalGet;
```

## 段階 1 で行わないこと

AI への質問、音声・写真の送信、ログイン、学習履歴の保存・同期、PDF 保存、授業モードはありません。
「AI は準備中」と質問欄は表示だけで、押せません。
問題・採点・経験値や理科クエストとの連携も、この段階では実装しません。
