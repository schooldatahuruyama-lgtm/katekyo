# 段階 2 の検証（使い捨て）: 無料の AI で中 1「光」を教えられるか

アプリ本体には入れない、確かめるためだけの道具です。確かめ終わったら、Cloudflare の Worker ごと消してかまいません。

## 何を確かめるか

1. **質問のテスト（16 問）**: 中 1「光」の質問に、日本語で正しく・やさしく答えられるか。範囲外の質問や、理科に関係のない話をどう扱うか。
2. **図のテスト（6 問）**: 「入射角を 60° に」「全反射するように」などの課題に対して、盤の配置データ（JSON）を正しく作れるか。アプリ本体の検査と計算で、自動で ○× を付けます。
3. かかる時間（1 回あたりの秒数）。

答えの正しさ（1.）は、結果を Claude Code に貼ってもらい、Claude Code が 1 問ずつ判定します。最後は先生にも見ていただきます。

## 手順（Cloudflare のダッシュボードで。メニューの名前は少しちがうことがあります）

1. https://dash.cloudflare.com/ にログインし、左のメニューの **Workers & Pages** を開く。
2. **Create application**（作成）→ Worker を新しく作る（「Hello World」のような、いちばん簡単なひな形でよい）。名前は `hikari-ai-check` など。**Deploy** を押す。
3. できた Worker の **Edit code**（コードを編集）を開き、はじめから入っているコードを全部消して、このフォルダの `worker.js` の中身を全部貼る。
4. 貼ったコードの上のほうにある `const CODE = 'CHANGE-ME';` の `CHANGE-ME` を、好きな合言葉（半角の英数字 8 文字以上）に変える。**合言葉はチャットに貼らないでください。**
5. Worker の **Settings**（設定）→ **Bindings**（バインディング）→ **Add**（追加）→ **Workers AI** を選び、変数名（Variable name）を `AI` にして保存する。
6. **Deploy**（デプロイ）を押す。
7. Worker のページに出ている `https://hikari-ai-check.<あなたの名前>.workers.dev` の URL を、パソコンのブラウザで開く。
8. 合言葉を入れ、「1. 質問のテスト」を押す。終わったら「2. 図のテスト」を押す。
9. 「コピー」を押して、結果をチャットに貼る。

## 使う量の目安

- はじめから印の付いている 4 つのモデルで両方のテストを行うと、1 日の無料枠（10,000 ニューロン）のうち、およそ 1,000 を使います。
- 下の 2 つの大きいモデル（120b・70b）にも印を付けると、さらに 2,500 ほど使います。くらべるためのもので、必須ではありません。
- 無料枠を超えるとエラーになるだけで、料金はかかりません（Cloudflare の料金のページの記載。2026-11-22 に確認）。

## 守っていること

- 合言葉が合わないと、AI は呼ばれません。合言葉を `CHANGE-ME` のままにすると動きません。
- 使えるモデルは、コードに書いた 6 つだけ。質問は 2,500 文字まで、答えは 500 トークンまで。
- 生徒の情報は扱いません。質問はコードに書いた固定の文だけです。
- 図の検査には、公開版（`https://schooldatahuruyama-lgtm.github.io/katekyo/js/…`）の検査と計算のプログラムを読みこんで使います。

## うまくいかないとき

| 画面に出る文 | 直し方 |
|---|---|
| 合言葉（CODE）を 8 文字以上に変えてから… | 手順 4 を行い、もう一度 Deploy |
| 合言葉がちがいます | ページに入れた合言葉を確かめる |
| Workers AI のバインディング（変数名 AI）がありません | 手順 5 を行い、もう一度 Deploy |
| エラー（モデルの名前や利用の上限の文） | そのまま「コピー」して貼ってください。結果に入っています |
