# 実装指示書: 「音の世界」の単元 その 1（計算・シーン・盤の定義・台本の読み取り）

## 目的

設計書 `docs/superpowers/specs/2026-11-25-more-units-design.md`（以下「設計書」）の 3.2・3.4・4・5.1〜5.3・6 章。
中 1「音の世界」の 3 つの盤（`sound-wave`・`sound-string`・`sound-speed`）の、**画面に依存しない部分**を作る。
画面（`js/board-view.js`・`js/app.js`・`index.html`・`sw.js`・`css/`）は、次の指示書（その 2）で作る。**この指示書では変えない**。

先に読むもの: 設計書の 3.2 節・4 章・5.1〜5.3 節・6 章、`docs/reports/sound-boards-draft.md`、`content/scripts-sound.js`（Claude Code が書いた台本。変えない）。

## 設計書と変える所（Claude Code の判断。こちらを優先する）

1. **音の単元にも音声がある**。`content/voice-sound.js` と `assets/audio/sound/**` は Claude Code が `tools/make-voice.mjs --set sound` で作る（この指示書では作らない・変えない）。単元の定義は `voice` の項目を持たない。設計書 3.3 節・3.4 節の「準備中です」の表示、音声のない盤の特別な扱いは**作らない**。
2. **読む時間**（設計書 3.4 節）は、単元によらず「音声なしで見る」のときに当てる（光の単元もふくむ）。この指示書では `explain.buildTimeline` の `options.readMs` と `config` の値までを作る。
3. 台本は 6 体ぶんがすでにある（`content/scripts-sound.js`）。先生の一覧は `scripts-light.js` のものを参照している。
4. 台本の描く指定は、下の「台本の描く指定」の名前を使う（設計書 5.3 節の案と少しちがう。`el:oscillo` はなく `grid` がある。`label:speed` と `point:tuning-fork` がある）。

### `js/sound.js`（新しく作る。`js/optics.js` と同じ形のモジュール。`root.Hikari.sound`）

画面に依存しない。引数が有限の数でない・範囲外のときは `null` を返す（例外を出さない）。

- `cycles(frequencyHz, windowSec)` → 波の数（`frequencyHz × windowSec`）
- `stringFrequency(lengthPercent, thickness, tension)` → `200 × (100 ÷ 長さ) × √張り ÷ √重さ`。`thickness` は `'thin'|'thick'`、`tension` は `'weak'|'strong'`。ほかの値は `null`
- `compare(a, b)` → `'higher'|'same'|'lower'`（a が b より大きい・同じ・小さい。相対誤差 1e-9 以内は `'same'`）
- `delayTenths(distance)` → `distance ÷ 34` の整数（34 の倍数でないときは `null`）
- `wavePoint(frequencyHz, amplitude, tSec)` → 時刻 `tSec` の高さ（目もりの数。`amplitude × sin(2π × frequencyHz × tSec)`。はじめは 0 から上へ）

### `js/scene.js`

- `KINDS` に `sound-wave`・`sound-string`・`sound-speed` を足す（光の 6 種類の後ろ）。「kind を6種類の盤から選んでください」の文は、数を言わない文にする。
- シーンの形は設計書 5.2 節の 3 つ。`validateScene` は、設計書 4 章の範囲・きざみ・型を確かめる。
- `trace(scene)` は、今の `{ rays, angles, images, marks, notes, measures }` に **`sound`** の項目を足して返す（光の盤では `sound` は `null`）。描く形はすべてエンジンが決める。`board-view.js` が自分で計算しなくてよいよう、盤の座標の点で返す。
  - `sound-wave`: `sound = { kind, fork: {x,y}, grid: { x, y, width, height, cols, rows, cellW, cellH, axisY }, wave: { points: [{x,y}…] }, amplitude: { from, to, guide: { from, to } }, period: { from, to, y }, labels: {…} }`
    - `wave.points` は左はしから右はしまで、横 2 単位以下のきざみの点（山の高さが正しく出るよう、山と谷の頂上の点を必ずふくむ）。
    - `amplitude`: 1 つ目の山の真下の横軸の点（`from`）から山の頂上（`to`）までの矢印。`guide` は頂上から振幅のつまみまでの横の破線。
    - `period`: 1 つ目の山から次の山まで。次の山が盤の方眼の外になるとき（振動数が 125 Hz より小さい）は、振動の始まり（左はし）から 1 回の振動の終わりまで。
    - `measures = { frequencyHz, amplitude, cycles, periodSec }`
  - `sound-string`: `sound = { kind, box: {x,y,width,height}, string: { from, to, thick: true|false }, bridge: {x,y}, vibration: { from, to, heightPx }, grid, wave, amplitude, labels }`
    - 波の振動数は `sound.stringFrequency`、振幅ははじく強さ（1〜4 目もり）。
    - `measures = { pitch, loudness, thickness, tension, lengthPercent, pluck, cycles }`。`pitch` は `higher|same|lower`、`loudness` は `louder|same|softer`。くらべる相手は `config.sound` のはじめの配置。**Hz の数は `measures` に入れない**（生徒に見せない値を画面の層へ渡さない）。
  - `sound-speed`: `sound = { kind, firework: {x,y}, ground: { from, to }, listener: { x, feetY, ear: {x,y}, eye: {x,y} }, waves: [{ cx, cy, r, startDeg, endDeg }…], distanceArrow: { from, to }, labels }`
    - `rays` に、花火から目までの光の線を 1 本（`role: 'light'`、`style: 'dotted'`）。
    - `waves` は花火を中心にした弧。いちばん外の弧は耳を通る。弧は盤の中に収める。
    - `distanceArrow` は花火（音源）から耳までの斜めの線に沿い、光の線のすぐ上（光の線と重ならない）。
    - `measures = { distance, delayTenths, delaySec, speed: 340 }`
  - `labels`（盤に書く文字。文もエンジンが作る）: `marks` に足す形でよい。キーと文:
    - `tuning-fork`「おんさ（音源）」、`grid`「1 目もり ＝ 0.001 秒」、`amplitude`「振幅」、`period`「1 回の振動」、`frequency`「振動数 250 Hz」
    - `string`「弦」、`bridge`「ことじ」
    - `firework`「花火（音源）」、`listener`「見る人」、`distance`「680 m」、`time`「2.0 秒後に聞こえる」、`speed`「音の速さ 約 340 m/s」
    - 数は `measures` と同じ値から作る（時間は `delayTenths` から小数 1 けたで作り、浮動小数の割り算の結果をそのまま出さない）。
- `handles(scene)`:
  - `sound-wave`: 振幅（`elementId: 'wave', handle: 'amplitude'`、ラベル「振幅」）と振動数（`handle: 'frequency'`、ラベル「振動数」）
  - `sound-string`: ことじ（`handle: 'bridge'`、ラベル「ことじ」）とはじく強さ（`handle: 'pluck'`、ラベル「はじく強さ」）
  - `sound-speed`: 見る人（`elementId: 'listener'`、ラベル「見る人」）
- `moveElement`: 範囲のはしで止め、いちばん近いきざみに乗せる。振動数は、**つまみの位置（1000 ÷ 振動数 目もり）が指にいちばん近いきざみ**をえらぶ。
- `setOption`: `sound-string` の `thickness`（`thin|thick`）・`tension`（`weak|strong`）。

#### 盤の上の位置（`config.sound.layout`。盤は 600 × 420）

- `sound-wave`: 方眼は 左 130〜右 570（1 目もり 44）、横軸の高さ 210、縦の 1 目もり 40（上下 4 目もり、50〜370）。おんさは (60, 210) のあたり。振幅のつまみは 左から 9 目もりの縦線の上、高さは横軸から振幅の分だけ上。振動数のつまみは横軸の上、左から (1000 ÷ 振動数) 目もり。
- `sound-string`: モノコードの箱は 左 60〜右 540・上 90〜下 140。弦は高さ 90、左の止め (80, 90) から右 (520, 90)。ことじの横の位置は `80 + 440 × 長さ ÷ 100`。はじく強さのつまみは、ふるえる部分のまん中の上、高さ `90 − 12 × 強さ`（上下に動く）。波の方眼は 左 80〜右 520（1 目もり 44）、横軸の高さ 290、縦の 1 目もり 25（190〜390）。
- `sound-speed`: 地面の高さ 360。花火は (70, 80)。見る人の横の位置は `128 + (距離 − 170) ÷ 1530 × 432`（170 m → 128、680 m → 272、1700 m → 560）。耳の高さ 300 のあたり。つまみは見る人の体の上（左右に動く）。
- 細かい数は作る人に任せるが、上の数と、設計書 3.2 節のつまみの決まり（`sound-wave` の 2 つのつまみがいつも盤の中にあり、中心が 1 目もり以上はなれる）を守る。

### `js/explain.js`

- 台本の描く指定を足す（`parseDraw`・`resolve`）。**台本の描く指定**:
  - `el:tuning-fork`・`el:string`（箱と弦と「弦」）・`el:bridge`・`el:firework`・`el:listener`（地面と見る人と「見る人」）
  - `grid`（方眼と「1 目もり ＝ 0.001 秒」）、`wave`、`amplitude`（矢印と「振幅」。`sound-wave` では破線もふくむ）、`period`（区切りと「1 回の振動」）、`vibration`、`sound-waves`、`distance`（矢印と値）
  - `label:frequency`・`label:time`・`label:speed`
  - `ray:light`
  - `point:tuning-fork`・`point:wave`・`point:bridge`・`point:distance`（`point:controls` は今のまま。`sound-string` の切り替えを指す）
- `resolve` が返す参照（`ref.source`）に `sound` を足してよい（例: `{ source: 'sound', key: 'wave' }`）。項目の `type` は、今のもの（`element`・`line`・`text`・`point` など）を使うか、要るなら足す（波は左から右へ描かれていく線、弧は中心から外へ順に現れる、など。時間は `config.explain` の今の値を使う）。
- `resolve` の `options` は `sound-string` の `thickness`・`tension` も返す。
- `buildTimeline` に `options.readMs`（手ごとの読む時間の配列。ミリ秒）を足す。`duration ＝ max(描く時間, 音声 ÷ 速さ, readMs ÷ 速さ) ＋ 間 ÷ 速さ`。`readMs` では描く時間を引きのばさない。
- `readMs(text)` を足す: `max(readMinMs, 字数 × readCharMs)`。字数は `Array.from` で数える。
