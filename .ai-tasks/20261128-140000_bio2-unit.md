見本（ユーザー承認済み）: `docs/mockups/unit-bio2-mockup.html`。

## 盤 1: 光合成（`bio-photosynthesis`）

- 名前「光合成」／問いかけ「植物は、何を使って何をつくる？」／見出し「光合成に必要なものをしらべよう」
- 案内の文: 「ふ入りの葉の一部をアルミニウムはくでおおい、光を当ててから、ヨウ素液でデンプンがあるかをしらべます。」
- 操作の説明: 「下のボタンで、葉のどこをしらべるかをえらべるよ。」
- シーン: `{ id: 'bio-photosynthesis-basic', kind: 'bio-photosynthesis', elements: [{ id: 'picture', type: 'picture' }], options: { light: 'on', part: 'green' } }`
- 切り替え: 「光」`on`「当たる所」・`off`「はくでおおった所」／「葉の部分」`green`「緑色の部分」・`white`「ふ（白い部分）」
- 画像 `body-2-c2.jpg`（左: 実験の前の葉。右: 脱色してヨウ素液につけた葉）。名前と文字:
  - `fu`「ふ（白い部分）」: 左の葉の (62,96) を指す。文字は左上。
  - `foil`「アルミニウムはく」: 引き出し線なし。はくの上 (156,176)。
  - `iodine`「脱色して、ヨウ素液につける →」: 2 つの葉の間の下 (320,400)。gray。
  - `under`「はくの下」: 右の葉の (480,182)。引き出し線なし。
- しらべる所の輪（`rings`。左右の葉の同じ所に 1 つずつ。半径は画像の 40px）:

| 光 | 葉の部分 | 左の葉 | 右の葉 | 結果 |
|---|---|---|---|---|
| on | green | (150,255) | (480,255) | デンプンができる（青紫色になる）。輪は green |
| off | green | (160,175) | (480,180) | できない（色が変わらない）。理由「光が当たらない」。輪は red |
| on | white | (62,96) | (360,130) | できない。理由「葉緑体がない」。輪は red |
| off | white | (45,175) | (355,185) | できない。理由「光が当たらず、葉緑体もない」。輪は red |

- 上に `title`: できるとき「デンプンができる（青紫色になる）」（green）、できないとき「デンプンができない（色が変わらない）」（red）。右の葉の輪のそばに `result`「青紫色」（green）または「変わらない」（red）。
- `measures = { light, part, starch: true|false, reason: null|'no-light'|'no-chloroplast'|'both' }`
- 盤の下の値: 「しらべた所 緑色で光が当たった所」（ほか「緑色ではくの下」「ふで光が当たった所」「ふではくの下」）／「ヨウ素液 青紫色になる」または「ヨウ素液 色が変わらない」／「デンプン できている」または「デンプン できていない（光が当たらない）」など理由つき。
- ためしてみよう: 「光を『はくでおおった所』にして、色が変わらないことをたしかめよう。」（off・green）／「葉の部分を『ふ』にして、光が当たっても色が変わらないことをたしかめよう。」（on・white）／「はくでおおった『ふ』の所もしらべよう。」（off・white）

## 盤 2: 消化と吸収（`bio-digestion`）

- 名前「消化と吸収」／問いかけ「食べ物は、体の中でどう変わる？」／見出し「栄養分が分解されるようすをたどろう」
- 案内の文: 「食べ物の栄養分は、消化液にふくまれる消化酵素のはたらきで、吸収されやすい物質に分解されます。」
- 操作の説明: 「下のボタンで、栄養分と見る所を切り替えられるよ。」
- シーン: `options: { nutrient: 'starch', stage: 'digest' }`（ほかは盤 1 と同じ形。id は `bio-digestion-basic`）
- 切り替え: 「栄養分」`starch`「デンプン」・`protein`「タンパク質」・`fat`「脂肪」／「見る所」`digest`「消化（分解）」・`absorb`「吸収（柔毛）」
- **消化**（画像 `digestion.svg`）。名前（どれも引き出し線つき）: `mouth`「口」(308,92)、`esophagus`「食道」(320,140)、`stomach`「胃」(358,214)、`liver`「肝臓」(266,200)、`gall`「胆のう」(282,226)、`pancreas`「すい臓」(364,262)、`small`「小腸」(360,334)、`large`「大腸」(260,330)。文字は、左がわの器官（肝臓・胆のう・大腸・口）は左、右がわ（食道・胃・すい臓・小腸）は右に置く。
  - はたらく所の名前を red にし、文に消化液を足す:

| 栄養分 | red になる名前と文 | 上の `title`（red） |
|---|---|---|
| starch | 「口（だ液）」「すい臓（すい液）」「小腸（かべの消化酵素）」 | 「デンプン → ブドウ糖」 |
| protein | 「胃（胃液）」「すい臓（すい液）」「小腸（かべの消化酵素）」 | 「タンパク質 → アミノ酸」 |
| fat | 「すい臓（すい液）」「肝臓（胆汁をつくる）」「胆のう（胆汁をためる）」。肝臓・胆のうは orange（消化酵素をふくまないため） | 「脂肪 → 脂肪酸とモノグリセリド」 |

  - 下に `texts`「赤い文字 ＝ 消化酵素がはたらく所」（gray）。fat のときは「だいだいの文字 ＝ 胆汁（消化酵素をふくまないが、脂肪の分解を助ける）」も。
- **吸収**（画像 `villus.svg`。柔毛 1 本を大きくした模式図）。名前: `villus`「柔毛」(320,125)、`capillary`「毛細血管」(262,280)、`lymph`「リンパ管」(320,330)、`wall`「小腸のかべ」(120,430)。
  - starch・protein: `capillary` が red、`title`「ブドウ糖は、柔毛の毛細血管に入る」（protein は「アミノ酸は、…」）。
  - fat: `lymph` が red、`title`「脂肪酸とモノグリセリドは、柔毛で再び脂肪になって、リンパ管に入る」。
- `measures = { nutrient, stage, product, into: 'capillary'|'lymph' }`
- 盤の下の値: 「栄養分 デンプン」「できる物質 ブドウ糖」「吸収される所 柔毛の毛細血管」（protein: アミノ酸・柔毛の毛細血管。fat: 脂肪酸とモノグリセリド・柔毛のリンパ管）
- ためしてみよう: 「栄養分を『タンパク質』にして、胃液がはたらくことを見よう。」（protein・digest）／「栄養分を『脂肪』にして、胆汁をつくる所を見つけよう。」（fat・digest）／「見る所を『吸収』にして、脂肪がリンパ管に入ることをたしかめよう。」（fat・absorb）

## 盤 3: 血液の循環（`bio-circulation`）

- 名前「血液の循環」／問いかけ「血液は、体の中をどうめぐる？」／見出し「血液の通り道をたどろう」
- 案内の文: 「血液は、心臓から出て肺や全身をめぐり、また心臓にもどります。心臓の 4 つの部屋と血管をたどりましょう。」
- 操作の説明: 「下のボタンで、循環と血液の向きを切り替えられるよ。」
- シーン: `options: { route: 'body', flow: 'out' }`（id は `bio-circulation-basic`）
- 切り替え: 「循環」`body`「体循環」・`lung`「肺循環」／「血液の向き」`out`「心臓から出る」・`back`「心臓にもどる」
- 画像 `heart.svg`（青 ＝ 静脈血、赤 ＝ 動脈血でぬってある。図の左が体の右）。名前（引き出し線つき）: `ra`「右心房」(270,200)、`rv`「右心室」(262,290)、`la`「左心房」(370,200)、`lv`「左心室」(368,290)、`vena`「大静脈」(252,100)、`pa`「肺動脈」(200,130)、`pv`「肺静脈」(448,196)、`aorta`「大動脈」(440,74)。右心房・右心室・大静脈・肺動脈の文字は左、ほかは右。`label:chambers` は 4 つの部屋の名前ぜんぶ。
  - 今たどっている部屋と血管の名前を目立たせる（動脈血は red、静脈血は blue 相当 ＝ 今の色の `bluePen`。`tone: 'blue'` を足してよい）。ほかは ink。

| 循環 | 向き | 目立たせる名前 | 上の `title` | 流れる血液 |
|---|---|---|---|---|
| body | out | 「左心室」「大動脈（全身へ）」red | 「体循環: 左心室 → 大動脈 → 全身」 | 動脈血 |
| body | back | 「大静脈（全身から）」「右心房」blue | 「体循環: 全身 → 大静脈 → 右心房」 | 静脈血 |
| lung | out | 「右心室」「肺動脈（肺へ）」blue | 「肺循環: 右心室 → 肺動脈 → 肺」 | 静脈血 |
| lung | back | 「肺静脈（肺から）」「左心房」red | 「肺循環: 肺 → 肺静脈 → 左心房」 | 動脈血 |

  - 下に `texts`「青 ＝ 静脈血（酸素が少ない）」「赤 ＝ 動脈血（酸素が多い）」「図の左が、体の右」（色だけで区別しない: 文字で書く）。
- `measures = { route, flow, chamber, vessel, blood: 'arterial'|'venous' }`
- 盤の下の値: 「体循環 心臓から出る」／「通る所 左心室 → 大動脈」／「流れる血液 動脈血（酸素が多い）」（表のとおり）
- ためしてみよう: 「『肺循環』の『心臓から出る』にして、肺動脈に静脈血が流れることをたしかめよう。」（lung・out）／「『肺循環』の『心臓にもどる』にして、肺静脈に動脈血が流れることをたしかめよう。」（lung・back）／「『体循環』の『心臓にもどる』にして、血液がもどる部屋を見つけよう。」（body・back）

## 盤 4: 刺激と反応（`bio-reflex`）

- 名前「刺激と反応」／問いかけ「熱いものにふれると、なぜすぐ手を引っこめる？」／見出し「信号が伝わる道すじをたどろう」
- 案内の文: 「刺激の信号は、神経を通って伝わります。意識して起こる反応と反射で、信号の通り道をくらべましょう。」
- 操作の説明: 「下のボタンで、反応の種類と、たどる所を切り替えられるよ。」
- シーン: `options: { kind: 'reflex', spot: 'skin' }`（id は `bio-reflex-basic`）
- 切り替え: 「反応」`reflex`「反射」・`conscious`「意識して起こる反応」／「たどる所」`skin`「皮ふ」・`sensory`「感覚神経」・`spinal`「せきずい」・`brain`「脳」・`motor`「運動神経」・`muscle`「筋肉」
  - `kind` ＝ reflex のとき「脳」はえらべない（理由「反射では、命令はせきずいから出ます（脳で考える前に反応します）」）。値は覚えておき、conscious にもどすと元にもどる。reflex で `spot` が brain だったときは、`spinal` をえらんだものとして扱う（図・値・判定とも。覚えている値は brain のまま）。
- 画像: reflex → `reflex.svg`、conscious → `conscious.svg`（信号の矢印は画像に描いてある。青 ＝ 感覚神経、赤 ＝ 運動神経）。名前: `skin`「皮ふ（感覚器官）」(40,250)、`sensory`「感覚神経」(250,180)、`spinal`「せきずい」(500,340)、`brain`「脳」(500,80)、`motor`「運動神経」(360,326)、`muscle`「筋肉」(190,300)。文字は、絵と矢印に重ならない所（作る人が決める）。
  - えらんだ所の名前を green にし、その所に輪（`rings`）。
  - 上に `title`: reflex「反射: 脳で考える前に、せきずいから命令が出る」、conscious「意識して起こる反応: 脳で判断して、命令を出す」。
  - 下に `texts`「信号が通る順: 皮ふ → 感覚神経 → せきずい → 運動神経 → 筋肉」（conscious は「… → せきずい → 脳 → せきずい → 運動神経 → 筋肉」）。
- `measures = { kind, spot（扱う値）, order（何番目。脳は conscious で 4）, steps: 5|7 }`
- 盤の下の値: 「反射」または「意識して起こる反応」／「えらんだ所 皮ふ（1 番目）」など／はたらき: skin「刺激を受けとる」、sensory「信号を、せきずいへ伝える」、spinal（reflex）「命令を出す」・（conscious）「信号を、脳へ伝える」、brain「判断して、命令を出す」、motor「命令を、筋肉へ伝える」、muscle「ちぢんで、手を動かす」
- ためしてみよう: 「反応を『意識して起こる反応』にして、通り道のちがいを見よう。」（conscious）／「意識して起こる反応で『脳』をえらんで、命令を出す所をたしかめよう。」（conscious・brain）／「反射で『せきずい』をえらんで、命令を出す所をたしかめよう。」（reflex・spinal。`spot` が brain のまま reflex にもどした場合は、できたにしない: 実際に「せきずい」を押したときだけ）
