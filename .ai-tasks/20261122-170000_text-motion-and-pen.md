# 実装指示書: 文字の出方を動画のようになめらかにし、ペンを絵にする

## 目的

設計書 `docs/superpowers/specs/2026-11-22-explain-animation-design.md` 2.3（描き方）。
ユーザーの指摘（2026-11-22）:
- 「まだ文字の出し方がカクついて感じる」
- 「重要語句は今みたいな出し方でいいが、全部の文字を今みたいに出さないで、動画のようになめらかに動いているように出してほしい」
- 「ペンは画像で作るか、アイコンを作ってほしい」

## 決めたこと

### 1. 盤の中の文字を、2 種類に分ける

- **重要語句**: その文字を描く手の台本の文に、「」で囲んで出てくる言葉と同じ文字（例: 反射の盤の 3 手目の「法線」、5 手目の「入射角」）。**今の出方（左から右へ書かれていく。ペンが先を追う）のまま**。
- **それ以外の文字**（例: 「鏡」「スクリーン」「空気」「水」「物体」「見る人」、角度の数字、台本でまだ「」に入っていない言葉）: **ふわっと浮き上がるように現れる**。不透明度 0 → 1、位置は画面上で下に 6px の所から元の位置へ、`easeOut`。ペンは追わない。
  - 角度の数字は、ふわっと現れながら、大きさ 0.85 → 1。
- 判定は `js/explain.js` で行う: `buildTimeline` が、各手の台本の文（どの先生の文でも用語は同じなので、`steps[i].lines` のどれか 1 つ）から「」の中の言葉を取り出し、その手の parts の item のうち `type: 'text'` で、表示する文字がその言葉と同じものに `key: true` を付ける。それ以外の text は `key: false`。
  - 表示する文字は、item が指す先（`marks` の `text`、つまみの `label`、角度の `name`、像の名前）から求める。角度の数字（`valueDeg`）は必ず `key: false`。
- それ以外の文字の描く時間は、文字数に関係なく 400ms（`config.explain` に足す）。重要語句は今までどおり 1 文字 90ms・最短 300ms。

### 2. 吹き出しの言葉を、切りかわるときになめらかにする

- 手が変わって吹き出しの言葉が変わるとき、新しい言葉が、ふわっと現れる（不透明度 0 → 1、画面上で下に 4px の所から、250ms、`ease-out`）。CSS の `animation` で行う（コマごとに JS で動かさない）。
- 吹き出しの言葉の中の「」で囲んだ重要語句には、黄色のマーカー（`linear-gradient(transparent 62%, #FFE08A 62%)`）が、左から右へ引かれる（`background-size` を 0% → 100%、500ms、言葉が現れた 200ms あとから）。「」の記号はそのまま表示する。
- 言葉は `textContent` と要素の組み立てで作る（`innerHTML` を使わない）。「」の中を `<mark class="term">` にする。
- 「ここまでの説明」に足される新しい行も、ふわっと現れる（200ms）。
- `prefers-reduced-motion: reduce` の端末では、これらの動きを付けない（すぐ出す。マーカーは、はじめから引かれた形）。

### 3. ペンを、絵（アイコン）にする

- `assets/pen.svg`（Claude Code が描いた。えんぴつの絵。先は絵の左下、64 × 64 のうちの (6, 58)）を使う。今のペンの印（丸と四角）はやめる。
- 盤の SVG の中に `<image>` で 1 つだけ置き、位置と不透明度だけを変える。大きさは画面上で 36px（`36 × unitPerPx`）。えんぴつの先が、描いている点に合うように置く。
- **ペンは飛ばずに、すべるように動く**: 描いている点が変わったら、ペンはその点へ向かってなめらかに動く（前の位置と目標の位置の間を、時間に対して指数的に近づく。半分まで近づく時間が 60ms。コマの間隔が変わっても同じ速さに見えること）。線を描いている間は、線の先にぴったり付く（おくれて見えないよう、線・弧・重要語句を描いている間は、目標との差が画面上で 2px 以内になるようにする。おくれるのは、次の描き始めへ移るときだけ）。
- ペンが出るのは、線・弧・重要語句を描いている間と、次の描き始めへ移っている間。ふわっと現れる文字・部品のときは、ペンはその場にとどまる。
- 手を描き終えたら、ペンは 200ms で消える（不透明度 1 → 0）。次の手で描き始めるとき、200ms で現れる。
- 自分で動かす状態では、ペンを出さない。
- `sw.js` の `PRECACHE` に `assets/pen.svg` を足し、`VERSION` を上げる。

### 4. 守ること（前の直しを保つ）

- 説明中は、絵を 1 回だけ作り、コマごとには属性だけを変える（`.ai-tasks/20261122-160000_smooth-animation.md` の決まり）。ペンの `<image>` も 1 回だけ作る。今のテスト（300 コマで要素の作成・削除が 0 回、など）が通ること。
- ペンをすべらせるための時刻は、`setState` に渡すか、外から渡せる時計で取る（テストで時刻を決められること）。

## 守ること

- 変更してよいファイル: `js/explain.js`（`key` を付ける・描く時間）、`js/config.js`（数値を足す）、`js/board-view.js`、`js/app.js`、`js/view-math.js`（足りない計算があれば足す）、`css/app.css`、`sw.js`、`tests/*.test.js`。
- 変更しない: `assets/`（`pen.svg` は Claude Code が置いた。直したほうがよい点は報告に書く）、`content/`、`tools/`、`docs/`、`js/voice.js`・`js/prefs.js`・`js/scene.js`・`js/boards.js`、`index.html`。
- 時間割のほかの部分（線・弧・部品の描く時間、声との合わせ方、手と手の間）と、動き（次へ・もどる・止める・速さ・音声・自分で動かす状態）を変えない。
- 外部ライブラリを使わない。git の状態を変えない。
