# 実装指示書: 画像の盤で、せまい画面のとき名前が画像から離れる（レビュー round 1 の指摘）

## 目的

`.ai-tasks/20261127-090000_bio1-unit.md` の画像の盤。Codex のレビュー `.ai-review/20261127-233521_round1.md` の 1 件を直す。

## 起きていること

盤の幅 335px・279px で、`bio-animals` の動物の名前（「は虫類」「哺乳類」など。引き出し線がない）が、置き場所の調整で画像の外（右の説明の所）へ動き、どの動物の名前か分からなくなる。

## 決めたこと

### 1. 名前は、指す相手のそばから出さない（3 盤とも）

- エンジンが、文字ごとに「動かしてよい範囲」（`bounds: { x, y, width, height }`。盤の座標）を返す。画面の層の置き場所の調整は、この範囲の中だけで動かす・折り返す。範囲がない文字は今までどおり。
  - 引き出し線のない名前（動物の 5 つの名前、`abrana-parts` の 4 つの名前、ならべた画像の上の題と下の `caption`）: その相手の画像の置き場所（動物は、その動物の絵のまわり）と、そのすぐ下の帯まで。
  - 引き出し線のある名前: 今までどおり盤の中を動いてよい（線でつながっているため）。ただし、線が別の名前の文字を横切らない。
- 範囲の中に、実表示 16px 以上の文字が収まらないときは、**文字を小さくしない・消さない・範囲の外へ出さない**。下の「せまい配置」に切り替える。

### 2. せまい配置（`compact`）

- 画面の層が、盤の表示の幅（px）から「せまい」を決めて、エンジンに伝える（`trace(scene, { compact: true })` のように。引数の形は作る人に任せる）。しきい値は `config.picture.compactBelowPx: 420`（盤の表示の幅）。幅が変わってしきい値をまたいだら、描き直す。説明中でも同じ。
- **`bio-animals` のせまい配置**:
  - 画像を大きくする（置き場所 x 20・y 44・幅 560・高さ 376 に、たてよこの比を保って収める ＝ 幅 501・高さ 376 を中央に）。
  - 5 つの名前は、それぞれの動物の絵の上か下に、その動物の範囲の中で置く（絵に重なってよいが、その動物の顔はかくさない。となりの動物の範囲に入らない）。合うなかまの輪と green は今と同じ。
  - 見出し（「あてはまるなかま: 魚類」）は盤の上の 1 行（収まらないときは 2 行）。
  - 右の説明（「えらんだ特徴」「〇 えらで呼吸」…「合う特徴の数」…）と、下の 2 行（「緑の輪 ＝ …」「画像の動物: …」）は、**盤の中には描かず、盤のすぐ下に文字（HTML）で出す**。順番は今と同じ（えらんだ特徴 3 行 → 合う特徴の数 → 緑の輪の説明）。エンジンが `picture.below: [{ key, text, tone }]` で返し、画面の層はそれを順に出すだけ。ふつうの配置では `below` は空。
  - 台本の描く指定 `side:<key>` は、せまい配置では盤の下の文字を指す（説明中は、その行がふわっと現れる・目立つ）。`point:` も同じ。解ける項目が 0 にならないこと。
- **`bio-flower`・`bio-plants`**: 画像の置き場所は変えない。`caption` と題は、自分の画像の列の幅の中で折り返す（2 行まで。3 行になるときは、`caption` を画像の下ではなく盤の下の文字（`below`）へ移す）。`bio-plants` の「なかまの例: …」と、えらべない理由の文も、収まらないときは `below` へ移す。
