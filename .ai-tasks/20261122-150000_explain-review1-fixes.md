## 直すこと

### 1. 作り直した音声が、前に開いた端末に届かない（High）

決めたこと: 音声の場所に、中身が変わると変わる印を付ける。
- `tools/make-voice.mjs` は直してある（Claude Code が変更済み）。`content/voice-light.js` の各音声の場所が `reflect/E/01.mp3?h=<12 文字の印>` の形になった。印は、読み上げ用の文・声・速さから作る。**`content/voice-light.js` と `tools/make-voice.mjs` は変更しない。**
- `sw.js`: 音声のキャッシュは、`?h=` を含めた URL をそのまま鍵にする（`ignoreSearch` を使わない）。同じ音声ファイルで印のちがう古いものが残っていたら、新しいものを保存したときに古いものを消す（同じパスで `?h=` だけちがうもの）。消すのに失敗しても、音声の取得は成功として返す。
- `tests/voice-light.test.js`: ファイルの実在を確かめるときは、`?h=…` を外したパスで見る。全部の音声の場所に `?h=` と 12 文字の印が付いていること、`assets/audio/light/manifest.json` の `hash` と一致することも確かめる。

### 2. 説明の途中で音声をオンにしたとき、すぐ再生できる保証がない（Medium）

今: 「音声なしで見る」で始めてから「🔇 音声オフ」を押すと、読みこみが終わったあとの処理の中で `play` を呼ぶ。iPad では断られるおそれがある。
決めたこと:
- 「音声なしで見る」「説明をとばして、すぐ動かす」で始めたときも、その盤・その先生の音声を、裏で読みこんでおく（`voice.prepare`）。読みこめなくても何も出さない（音声を使うと決めたときに知らせる）。
- 説明中の音声のボタンは 3 つの状態を持つ: 「🔇 音声オフ」（押すとオンにする）、「🔊 音声オン」（押すとオフにする）、「🔊 準備中…」（押せない）。
- 「🔇 音声オフ」を押したとき:
  - 音声の準備ができている → その押した処理の中で、待たずに今の手の声を頭から再生する。
  - まだ準備中 → ボタンを「🔊 準備中…」にして待つ。準備ができたら、**自動では再生せず**、ボタンを「🔇 音声オフ」に戻して押せるようにする（生徒がもう一度押したときに、その処理の中で再生する）。黄色の帯は出さない。
  - 読みこめなかった → 黄色の帯「音声を読みこめませんでした。文字だけで続けます。」ボタンは「🔇 音声オフ」。

### 3. 「次へ」で止めた声が、読みこみが終わったときに始まる（High）

決めたこと: 読みこみのあとに何かをする処理は、すべて「世代の番号」を持つ。次のどれかが起きたら番号を進め、古い番号の処理は何もしない: 次へ・もどる・止める・音声オフ・先生をかえる・とばす・ホームへ戻る・別の盤へ移る・もう一度説明を見る。
（2 の決めたことにより、読みこみのあとに自動で再生する道はなくなる。それでも、読みこみの結果でボタンの表示を変える処理に、この番号を使うこと。）

### 4. 端末への保存に失敗すると、通信で取れた音声まで失敗になる（Medium）

決めたこと: `sw.js` は、通信で status 200 の応答を取れたら、キャッシュへの保存（`cache.put`）が失敗しても、その応答を返す。保存の失敗は `console.warn` だけ。

### 5. 声の長さが不正なときの扱いが、描く側と再生の側でちがう（Medium）

決めたこと: 声の長さとして使ってよいのは「有限で 0 より大きい数（型が number）」だけ。それ以外（0・負・NaN・Infinity・数字の文字列・null）は、文字数から決めた長さ（`文字数 × 180ms + 1000ms`）を使う。
- この判断をする関数を 1 つにまとめ（`js/explain.js` に `clipSeconds(value, textLength) → 秒`）、時間割（`buildTimeline`）・`voice.play` に渡す秒数・`app.js` の全部が、これを通した値を使う。
- `voice.play` の中でも、渡された秒数が不正なら、待つ時間を 4 秒だけにせず、呼ぶ側が渡す代わりの秒数を使えるようにする（引数は今のまま。`app.js` が必ず `clipSeconds` を通した値を渡す）。
