## 画面の動き（設計書 2 章。見本と同じ）

### はじめの画面（盤を開いたとき）

- 盤のカードの上に重ねて出す（盤はうすく見えている）。
- 「だれに教えてもらう？」、6 体の先生（絵・名前・ひとこと（`tone`））を 3 列 × 2 行で並べる。えらんでいる先生に青い枠。`role="radiogroup"` と `role="radio"`、矢印キーで動かせること。
- えらんだ先生の下に「〇〇が、描きながら説明するよ。」
- ボタン 3 つ: 「🔊 音声ありで見る」（主）、「音声なしで見る」、「説明をとばして、すぐ動かす」（文字だけの小さめのボタン）。
- 「音声ありで見る」は、その盤・えらんでいる先生の音声を `voice.prepare` で読みこむ。読みこみ中は「🔊 準備中…」で押せない。先生をかえたら読みこみ直す。読みこめなかったときは、ボタンを「🔊 音声ありで見る」のまま押せる状態に戻し、押したら黄色の帯で知らせて文字だけで始める。
  - 音声の再生は、ボタンを押した処理の中で、待たずに `play` を呼ぶ（iPad の制限のため。読みこみを待ってから呼ばない）。
- クレジット「音声: VOICEVOX Nemo（女声 2・3・4、男声 1・2・3）」を小さく出す。
- はじめにえらばれている先生・音声のあり・なしの強調・速さは、`prefs.load` の値。えらんだら `prefs.save`。

### 説明中

- 盤のすぐ上に吹き出し（えらんだ先生の絵 48px と、今の言葉。18px・太字）。`aria-live="polite"`。
- 盤は `explain.stateAt` の状態を、`requestAnimationFrame` ごとに描く。つまみは出さない。盤にさわっても動かない。
- 描き方: 線は始点から終点へのびる。文字は 1 文字ずつ。弧は広がる。部品・像・影は、ふわっと現れる（大きさ 0.4 → 1、不透明度 0 → 1）。`point` は、相手のまわりに青い輪が広がって消える。描いている先に、ペンの印（見本と同じ形）。
- 文字の大きさ・線の太さ・文字の置き場所は、今の `view-math`（`sizes`・`placeLabels`）の決まりのまま。**置き場所は、全部描き終えた状態で計算した位置を使う**（描いている途中で文字が動かないようにする）。
- 盤の下の行（今の値）は、角度が描かれた手から出す（角度のない盤では、最後の手で出す）。
- 操作の帯（盤の下）: 「◀ もどる」「⏸ 止める / ▶ 再生」「次へ ▶」、進み具合の印（手の数だけの短い棒。済んだ手は青、今の手はうすい青）、「速さ」「−」「1 倍」「＋」、「🔊 音声オン / 🔇 音声オフ」、「先生をかえる」、「とばして自分で動かす」。ボタンは高さ 48px 以上。せまい画面では折り返す。
- パネル: 「ここまでの説明」として、今までの言葉を番号つきで並べる（今の手は太字）。
- 音声ありのときは、手の始まりで `voice.play`。次の手へ進むのは、描き終わり・声の終わり（`onEnd`）・間（1.5 秒 ÷ 速さ）の全部がそろってから。
- 途中で「🔊 / 🔇」を押す: オンにしたら今の手の声を頭から再生、オフにしたら声を止める。オンにしたときに音声をまだ読みこんでいなければ読みこむ（読みこめなければ黄色の帯）。
- 途中で速さを変える: 声は `player.setRate`、描く動きは、今の手の「進み具合（0〜1）」を保ったまま新しい速さで続ける。
- 黄色の帯（`role="status"`）: 操作の帯のすぐ上。文は設計書 3 章のとおり。

### 自分で動かす

- 最後の手が終わる、または「とばす」「説明をとばして、すぐ動かす」で、今までどおりの盤になる（つまみ・切り替え・「ためしてみよう」・「先生への質問は準備中です」・「はじめの配置にもどす」）。
- 吹き出しは残し、最後の言葉を出す。
- パネルのいちばん下に「▶ もう一度、説明を見る」。押すと、配置をはじめに戻して、はじめの画面へ。
- 今までパネルの上に出していた `intro`（キューブ先生の絵と案内の文）は出さない（吹き出しに置きかわるため）。

### ホーム

- 下の文の所に、クレジット「音声: VOICEVOX Nemo（女声 2・3・4、男声 1・2・3）」を足す。

### 画面の行き来・そのほか

- ホームへ戻る・ブラウザの戻る・別の盤へ移るとき: `player.stop()` して、説明を終える。
- `document.visibilitychange` で隠れたら、説明と声を止める（「▶ 再生」の状態にする）。
- 画面の幅が変わったら、今の手・今の進み具合のまま描き直す。
- `prefers-reduced-motion: reduce` の端末では、各 part の描く時間を 1ms として扱う（1 手ずつ完成した形で出る）。声と手の進み方は同じ。
- `?board=<id>` で直接開いたときも、はじめの画面から始まる。

### オフライン（`sw.js`）

- アプリ本体（HTML・CSS・JS・`content/*.js`・先生の絵 6 つ）は、今までどおり `PRECACHE`。
- 音声（`assets/audio/` の下）は `PRECACHE` に入れない。`fetch` を受けたら、音声用のキャッシュ（名前 `hikari-board-audio-v1`。アプリの `VERSION` が変わっても消さない）を先に見て、なければ通信して取り、成功した応答（status 200）だけを保存する。通信に失敗したら、失敗をそのまま返す（アプリ側が黄色の帯を出す）。
- `voice.js` に渡す `fetchClip` は、`fetch(url)` → `blob()` → `URL.createObjectURL`。応答が `ok` でなければ失敗にする。

## 守ること

- 見た目は見本に合わせる。見本にない部分（鏡の像・屈折・レンズの盤の描き方）は、今の盤の描き方のまま、途中まで描けるようにするだけ。
- 画面の文は、中学生向けのやさしい日本語。AI が使えるように見える表示をしない。
- `innerHTML` に、台本・URL・端末に覚えた値を入れない（`textContent` を使う）。
- 外部ライブラリ・外部の URL を使わない。端末に保存するのは `prefs` の 3 つの値と、Service Worker のキャッシュだけ。
- 今の動き（つまみで動かす、切り替え、「ためしてみよう」の ✓、「はじめの配置にもどす」、画面の行き来、不正な URL の知らせ、文字の置き場所の決まり）を変えない。今のテスト（その 1 のあとの全部）が通ること。
- 変更しない: `content/`、`assets/`、`tools/`、`docs/mockups/`、`docs/superpowers/`、`js/scene.js`・`js/optics.js`・`js/entry.js`・`js/geometry.js`・`js/boards.js`。`js/explain.js`・`js/prefs.js`・`js/voice.js`・`js/view-math.js`・`js/config.js` は、画面を作るうえで足りない関数があれば足してよい（今ある関数の動きは変えない。足したら報告に書き、テストも足す）。
- git の状態を変えない。
