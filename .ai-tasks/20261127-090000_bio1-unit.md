## 画像の盤のしくみ（新しく作る）

この単元の盤は、つまみがなく、**切り替えのボタンだけ**で図が変わる。図は「画像 ＋ 重ねる部品」でできている。光・音・力の盤と同じく、**何を描くかはエンジンが決め、画面の層は返されたものを描くだけ**にする。

- `trace(scene)` は `picture` の項目を返す（ほかの盤では `null`。画像の盤では `sound`・`force` は `null`）。
  ```js
  picture: {
    kind,
    images: [{ key, src, x, y, width, height, crop: { x, y, width, height } | null }],  // 盤の座標（600×420）の置き場所。crop は画像（640×480）の中の切り出す範囲（null は全体）
    pins:   [{ key, from: {x,y}, to: {x,y}, tone }],     // 引き出し線。to が画像の中の指す点
    tags:   [{ key, x, y, text, tone, anchor }],         // 白い下地つきの文字
    rings:  [{ key, cx, cy, rx, ry, tone }],             // 目立たせる輪
    texts:  [{ key, x, y, text, tone, size, anchor }],   // 下地なしの文字（見出し・横の文字）
  }
  ```
  - `tone` は `'ink' | 'red' | 'green' | 'gray' | 'orange'`。色は `config.colors` の今の色（`text`・`redPen`・`green`・`normal`・`ray`）に当てる。新しい色を足さない。色だけで区別しない（文で分かる）。
  - 文字（`tags`・`texts`）は `marks` にも入れ、置き場所の調整（`viewMath.placeLabels`）に使えるようにする。ただし `tags` の位置は、下の表の位置を基本とし、重なるときだけ動かす。
- 画像は `<image>` で描く。`crop` があるときは、その範囲だけを置き場所いっぱいに見せる（はみ出しは切る）。画像のまわりに細い枠（`#E3DBC8` 相当の今の色）。画像の `alt` に当たる説明は、盤の `aria-label` に入れる。
- 画像が読みこめないときは、その置き場所に「画像を読みこめませんでした」と出し、引き出し線と名前はそのまま出す（黙って空白にしない）。
- 画像は `sw.js` の `PRECACHE` に入れる（10 枚、合計 約 320 KB）。
- 説明中（描きながらの説明）: 画像は 400ms でふわっと現れる。引き出し線はペンで描かれ、重要語句（台本の「」の用語と同じ文字。「がく」「花弁」「子房」など）は書かれていく出し方、ほかの文字はふわっと出る。輪は線として描かれる。今の決まり（絵を 1 回だけ作り、コマごとには属性だけを変える）を保つ。
- 台本の描く指定（`content/scripts-bio1.js` の先頭のコメント）: `image`（`images` 全部）、`panel:1〜3`（`images` の n 枚目と、その `caption:n` の文字）、`label:<key>`（その key の `pins` と `tags`。`label:classes` は 5 つのなかまの名前ぜんぶ）、`title`（key が `title` の文字）、`side:<key>`（key が `side-<key>` の文字）、`ring`（`rings` 全部）、`point:<key>`（`title`・`controls`、または `tags` の key）、`controls`。

## 盤 2: 植物のなかま分け（`bio-plants`）

- 名前「植物のなかま分け」／問いかけ「植物は、どこを見ればなかま分けできる？」／見出し「特徴をえらんで、植物をなかま分けしよう」
- 案内の文: 「植物は、ふえ方や体のつくりで 5 つのなかまに分けられます。特徴を切り替えて、どのなかまになるか見てみましょう。」
- 操作の説明: 「下のボタンで、特徴をえらべるよ。」
- シーン: `{ id: 'bio-plants-basic', kind: 'bio-plants', elements: [{ id: 'picture', type: 'picture' }], options: { reproduce: 'seed', ovule: 'in', cotyledon: 'two', organs: 'yes' } }`
- 切り替え: 「ふえ方」`seed`「種子」・`spore`「胞子」／「胚珠」`in`「子房の中」・`naked`「むき出し」／「子葉」`two`「2 枚」・`one`「1 枚」／「根・茎・葉の区別」`yes`「ある」・`no`「ない」
- **関係のない特徴は、えらべなくする**（ボタンを使えない状態にし、理由を見出しの横か下に出す。値は覚えておき、えらべるようになったら元にもどる）:
  - `reproduce` ＝ spore のとき: 「胚珠」「子葉」はえらべない（理由「胞子でふえる植物には、胚珠や子葉がありません」）
  - `reproduce` ＝ seed のとき: 「根・茎・葉の区別」はえらべない（理由「種子でふえる植物には、根・茎・葉の区別があります」）
  - `reproduce` ＝ seed かつ `ovule` ＝ naked のとき: 「子葉」はえらべない（理由「子葉の数で分けるのは、被子植物です」）
  - `controls` の各項目に、えらべるかどうかと理由を返す仕組みを足す（`boards.get(id)` の `controls` を、今のシーンから求める関数にするか、`boards.controlState(id, scene)` を足す。作る人に任せる）。使えないボタンは `disabled` と、うすい色、理由の文で示す（色だけにしない）。使えないボタンを `setOption` しても、何も変わらない。
- なかま（`measures.group`）: seed・in・two → `dicot`「双子葉類（被子植物）」／seed・in・one → `monocot`「単子葉類（被子植物）」／seed・naked → `gymnosperm`「裸子植物」／spore・yes → `fern`「シダ植物」／spore・no → `moss`「コケ植物」
- 図: 上に `title`「なかま: 双子葉類（被子植物）」（green、大きめ）。下に `texts`「なかまの例: …」（gray）。

| なかま | 画像と置き場所 | 文字 |
|---|---|---|
| dicot | 3 枚ならべる（置き場所は x 20・212・404、y 84、幅 176、高さ 250）。1: `plants-3-c1.jpg` の crop (20,60,300,426)。2: `plants-3-c2.jpg` の crop (30,0,280,398)。3: `plants-3-c3.jpg` の crop (40,10,250,355) | 画像の上に「芽ばえ」「葉」「根」。下に `caption:1`「子葉は 2 枚」、`caption:2`「葉脈は網状脈」、`caption:3`「主根と側根」（green の下地つき）。例「アブラナ・タンポポ・エンドウ」 |

| gymnosperm | 2 枚ならべる（x 20 と 308、y 84、幅 272、高さ 250）。1: `plants-2-c2.jpg` 全体。2: `plants-2-r1.jpg` 全体 | 画像の上に「マツの枝」「りん片」。1 に名前「雌花」(306,30)・「雄花」(210,190)。2 に名前「胚珠（むき出し）」(138,380)。下に `caption:1`「花に花弁やがくがない」、`caption:2`「子房がなく、胚珠がむき出し」。例「マツ・スギ・イチョウ」 |

  - ならべる画像の crop は、切り出したい物（芽ばえ・葉・根）が置き場所の中に全部見えること。数は目安なので、ブラウザのテストではなく**指示書の数どおり**に入れ、報告に「目で確かめていない」と書く（Claude Code がブラウザで確かめて直す）。

- ためしてみよう: 「子葉を 1 枚にして、単子葉類の葉脈と根を見よう。」（group ＝ monocot）／「胚珠を『むき出し』にして、裸子植物を見つけよう。」（gymnosperm）／「胞子でふえて、根・茎・葉の区別がないなかまを見つけよう。」（moss）
