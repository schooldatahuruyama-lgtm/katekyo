## 作成・変更するファイル

### 1. `js/scene.js`（変更: 光線に役割を付ける）

- `trace` が返す `rays` の各要素に `role`（文字列）を足す。役割は設計書 4.2 の 2 つ目の表のとおり。
- `lens` の盤では、今 1 本の「レンズから先」の光線を、焦点（`lens.x + focalLength`, `lens.y`）で 2 本（`to-focus`・`beyond-focus`）に分ける。つないだ形は今と同じ。光軸の上の光線（高さ 0）も同じように分ける。
- `lens-image` の盤では、1 本目（光軸に平行 → 焦点）の 2 本に `ray1`、2 本目（中心を直進）の 2 本に `ray2`、3 本目（手前の焦点 → 平行）の 2 本に `ray3`、虚像の延長（破線）に `extension`。
- `role` を足す以外は変えない: 光線の位置・`style`・`arrow`・`angles`・`images`・`marks`・`notes`・`measures`・`moveElement`・`validateScene`。

### 2. `js/config.js`（変更: 数値を足す）

`explain`: 描く時間（部品 350、線 800、文字 1 文字 90・最短 300、弧 600、印 600。単位 ms）、手と手の間 1500、引きのばしの割合 0.8、声の長さが分からないときの 1 文字あたり 180ms と足す 1000ms、声の終わりを待つ上乗せ 4000ms、速さの一覧 `[0.5, 0.75, 1, 1.25, 1.5, 1.75, 2]`、はじめの速さ 1、文の長さの上限 75。

### 3. `js/explain.js`（新規。画面に依存しない）

台本と計算結果から、説明の時間割と「いま見せるもの」を求める。ブラウザでは `Hikari.explain`。

- `DRAW_KINDS`: `draw` に書けるものの一覧（設計書 4.2 の 1 つ目の表）。
- `parseDraw(token) → { kind, arg } | null`（例: `'ray:incident'` → `{ kind: 'ray', arg: 'incident' }`、`'normal'` → `{ kind: 'normal', arg: null }`。知らないもの・文字列でないものは null）
- `resolve(token, scene, traceResult, handles) → { kind, arg, items: [...] }`
  - `items` は、その `draw` が指す「描くもの」の一覧。1 つの item は `{ type: 'element'|'line'|'text'|'arc'|'image'|'shadow'|'point'|'handles'|'controls', ref: ... }` の形で、`ref` は相手を見つけるための値（部品の id、`rays` の添字、`marks` の key、`angles` の key など）。細かい形は任せるが、`board-view.js` がこれだけを見て描けること。
  - 当たるものがないときは `items: []`。
- `buildTimeline(steps, scene, traceResult, handles, options) → { steps: [...], total }`
  - `steps` は台本の 1 つの盤の手の配列（`scripts.BOARDS[boardId]`）。`options = { clipSeconds: number[] | null, rate: number, textLengths: number[] }`（`clipSeconds` は音声ありのときの各手の声の長さ。音声なしは null。`textLengths` は各手の文の文字数）。
  - 返す `steps[i]` = `{ index, start, drawDuration, duration, parts: [{ token, kind, arg, items, start, duration }] }`（時刻はすべて ms、1 倍速での値ではなく、`rate` を反映した実際の値）。計算は設計書 4.3 のとおり。
  - 声の長さが 0・負・数でない手は、`textLengths[i] × 180 + 1000` を声の長さとして使う（音声ありのときだけ）。
- `stateAt(timeline, stepIndex, localMs) → { stepIndex, parts: [{ token, kind, arg, items, progress }], stepDone }`
  - `stepIndex` の手の、手の始まりから `localMs` たった時点の状態。前の手までの parts は `progress: 1`、今の手の parts は 0〜1、あとの手の parts は入れない。`stepDone` は今の手を描き終えたか。
  - `stepIndex` が範囲外・`localMs` が負や数でないときは、いちばん近い正しい値に寄せる（例外を投げない）。
- `finalState(timeline)`: 全部描き終えた状態（`handles`・`controls` を含む）。
- `nextTarget(stepIndex, stepDone, count)`・`backTarget(stepIndex)`: 「次へ」「もどる」の行き先（設計書 2.3）。`nextTarget` は `{ action: 'finish-step' | 'go' | 'end', stepIndex }`。

### 4. `js/prefs.js`（新規）

端末に覚える 3 つの値。ブラウザでは `Hikari.prefs`。

- `KEY = 'hikari-board:prefs'`
- `defaults(teacherIds, defaultTeacher) → { teacher, voice: false, rate: 1 }`
- `normalize(value, teacherIds, defaultTeacher) → { teacher, voice, rate }`（設計書 3 章の 1〜2 行目。項目ごとに検査し、だめな項目だけはじめの値にする）
- `load(storage, teacherIds, defaultTeacher)`・`save(storage, prefs)`（`storage` は `localStorage` と同じ形のものを外から渡す。`storage` が null・`getItem`/`setItem` が例外を投げるときも、例外を外へ出さない。`save` は成功したかを真偽値で返す）

### 5. `js/voice.js`（新規。Audio を外から渡せる形）

ブラウザでは `Hikari.voice`。

- `RATES`（`config` の速さの一覧）、`stepRate(rate, direction) → rate`（`direction` は −1 か 1。端ではそのまま。一覧にない値を渡されたら 1 を返す）
- `createPlayer({ createAudio, fetchClip, setTimer, clearTimer, onProblem }) → player`
  - `createAudio()` は `<audio>` と同じ形のもの（`src`・`playbackRate`・`defaultPlaybackRate`・`play()`・`pause()`・`onended`・`onerror`）を返す。1 つだけ作って使い回す。
  - `fetchClip(url) → Promise<string>`（再生に使う URL を返す。ブラウザでは `fetch` → Blob → `URL.createObjectURL`。テストではにせもの）
  - `player.prepare(urls) → Promise<{ ok: boolean, failed: number }>`: 一覧の音声を読みこんで持っておく。1 つでも読めなければ `ok: false`。
  - `player.play(index, seconds, rate, onEnd)`: 持っている音声を再生する。終わったら `onEnd` を 1 回だけ呼ぶ。再生を断られた（`play()` の Promise が reject）・エラー・読みこんでいない場合は、`onProblem(種類)` を呼び（種類は `'load'` か `'blocked'`）、`onEnd` も呼ぶ（説明を止めない）。`seconds ÷ rate + 4 秒` たっても終わりの合図が来なければ、`onEnd` を呼ぶ。
  - `player.setRate(rate)`: 再生中の声にもすぐ反映する。
  - `player.pause()`・`player.resume()`・`player.stop()`（`stop` のあとは、前の `play` の `onEnd` を呼ばない）
  - 新しい `play` を呼んだら、前の `play` の合図は無視する（古い `onEnd` を呼ばない）。
  - `player.release()`: 作った Blob URL を解放する（`revoke` を外から渡せる形にしてよい）。
