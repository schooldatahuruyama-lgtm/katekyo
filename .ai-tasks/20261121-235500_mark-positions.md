# 実装指示書: 盤の中の固定の文字の位置（前の指示書 E の残り）

## 目的

設計書 `docs/superpowers/specs/2026-11-21-ai-tutor-stage1-design.md` 6.1（文字が線・つまみ・ほかの文字に重ならない）。
前の指示書 `.ai-tasks/20261121-233000_review1-fixes.md` の E は、`js/scene.js` の変更を許していなかったため残った。この指示書で、`trace` が返す `marks` の位置そのものを直す。

Claude Code がブラウザで見た今の様子: 反射の盤で「法線」と「鏡」が光の当たる点のすぐそばに重なって出る。凸レンズの盤で「焦点」「光軸」「焦点距離」が光軸と光線の上に出る。実像と虚像の盤で「焦点」「物体」「スクリーン」が光軸の上に出る。

## 直すこと

### 1. `js/scene.js` の `trace` が返す `marks` の位置（文字の左下の点）

| 文字 | 置く所 |
|---|---|
| 法線 | 描く法線の、光が来る側の端（当たる点からいちばん遠い端）の近く。法線の線から右へ 8 ずらす。鏡を傾けたら一緒に動く |
| 鏡（反射の盤） | 鏡の線の、「かたむける」のつまみと反対の端の近く。鏡の線から、光が来ない側（裏側）へ 24 離す。傾けたら一緒に動く |
| 鏡（鏡の像の盤） | 鏡の線の上の端の近く、裏側へ 10 |
| 空気・水・ガラス | 左の端（x = 16）。境界から、それぞれの側へ 28 離す |
| 焦点 | それぞれの焦点の点の真下。光軸から下へ 26。文字の中心を焦点の x に合わせる（左下の点は、その分だけ左） |
| 光軸 | 光軸の右の端の近く（x = 540 前後）、光軸から下へ 26 |
| スクリーン | スクリーンの線の上の端の近く、線の右へ 8 |
| ついたて | ついたての線の上の端の近く、線の右へ 8 |

- 位置は盤（0〜600、0〜420）の中に収める（はみ出すときは端で止める）。
- `marks` の `key` と `text` は変えない。

### 2. 光軸の上にあるつまみの文字（`js/view-math.js`・`js/board-view.js`）

- `placeLabels` の `labels` に、任意の項目 `prefer: 'below'` を足す。これがある文字は、候補の順を「下・上・右・左・右下・左下・右上・左上」にする。
- `board-view.js` は、つまみが光軸の上にあるとき（`lens` の盤の「焦点距離」、`lens-image` の盤の「物体」「スクリーン」）、その文字に `prefer: 'below'` を付ける。それ以外のつまみは今のまま（右から試す）。
