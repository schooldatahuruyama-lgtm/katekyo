## 画面の動き

### ホーム

- 上の帯: アプリの名前「ひかりボード」、通信の状態、「AI は準備中」。
- 見出し「つまずいたら、動かして確かめよう。」と、説明の 1 行。
- 「中 1 光の世界 ― ボードをえらぶ」の下に、`boards.list()` の 6 件を行で並べる（名前、問いかけ、→）。行の全体が押せる（`<button>` か `<a>`。高さ 52px 以上）。
- 下に「一度開けば、通信がなくても使えます。」
- `?board=` の `error` があるとき: 一覧の上に「指定された盤が見つかりませんでした」を出す（黄色の地、`role="status"`）。

### 盤の画面

- 上の帯: 「← ボード一覧」（押すとホームへ）、盤の名前、通信の状態、「AI は準備中」。
- 盤（SVG、`viewBox="0 0 600 420"`）: 左上に手書き風の見出し（`heading`）と黄色のマーカーの下線。`scene.trace` の `rays`（矢印つき）・`angles`（弧、数字、名前）・`images`・`marks`・`notes`、`scene.handles` のつまみ。紙は `#FAF7EE` に点の方眼。
- 盤のすぐ下の行（HTML）: `boards.readout` の値（`in` は青、`out` は赤、太字 18px）と、操作の説明（例: 「オレンジの丸（光源）は指で動かせるよ」。盤ごとに 1 文）。`trace` の `notes` もこの行に出してよい。
- パネル: キューブ先生（`assets/mascots/mascot_E.svg`、48px、`alt="キューブ先生"`）と `intro`。「ためしてみよう」の一覧（□ → 条件を満たしたら ✓ と「できた！」、緑の太字）。屈折の盤だけ切り替え（`controls`）。「先生への質問は準備中です（今は使えません）」（灰色の地、点線。押せない。ボタンにしない）。「はじめの配置にもどす」ボタン。
- 幅 900px より広いときは盤が左・パネルが右、900px 以下は盤が上・パネルが下。

### 盤の描き方（設計書 6.1 の決まり）

- 盤の文字・つかむ範囲・つまみの大きさは、`view-math.sizes(盤の表示幅)` から決める。表示幅が変わったら（`resize`、できれば `ResizeObserver`）描き直す。
- 線（`line`・`path`）には `vector-effect: non-scaling-stroke` を付け、画面上の太さを一定にする（光線 4.5px、法線・弧 2.5px、鏡・境界 3〜4px）。
- 手描き風のゆらぎ（SVG の `feTurbulence` + `feDisplacementMap`、`scale="1.4"`）は、鏡・境界・法線・光線の線だけに掛ける。文字とつまみには掛けない。
- 光線には向きの矢印を付ける。破線（`style: 'dashed'`）は、像へのばす延長線だけ。
- 角度は、弧と数字（太字）と名前。数字と名前の位置は `view-math.angleLabel`。`sizes.showAngleNames` が false のときは名前を出さない。
- つまみは、白地に濃い輪郭の丸（光源は `#B45C00` の塗り）と、まわりのうすい丸（つかむ範囲）。`handles` の `label` を近くに出す（文字は 16px 以上）。つかむ範囲は、見えない大きな円（`pointer-events: all`）で取る。
- 色だけで区別しない: 角度には名前、光線には矢印、できたものには ✓。

### 動かす

- `pointerdown` でつまみをつかみ、`setPointerCapture`。`pointermove` で `view-math.toBoardPoint` → `scene.moveElement` → 描き直し。`pointerup`・`pointercancel` で放す。
- 追うのは最初の 1 本の指だけ（つかんでいる間、ほかの `pointerId` は無視）。
- 盤の SVG には `touch-action: none`（動かしている間に画面がスクロールしない）。
- 動かすたびに「ためしてみよう」を `boards.checkPrompt` で調べる。一度 ✓ が付いたら消さない。
- キーボード: つまみに `tabindex="0"` と `aria-label`（`label`）を付け、矢印キーで 4 ずつ動かせる。

### 画面の行き来

- はじめに `entry.parseBoardParam(location.search, ids)` を読む。`boardId` があればその盤、なければホーム。
- 盤を開くとき `history.pushState` で URL を `?board=<id>` にする。ホームへ戻るとき `?board` を外す。ブラウザの戻る・進む（`popstate`）に合わせて画面を変える。
- `?board=` の値を、文字として画面に出さない（`innerHTML` に入れない）。

### 状態の表示

- 通信: `navigator.onLine` と `online`・`offline` のイベントで「オンライン」「オフライン（このまま使えます）」を切り替える。
- AI: 常に「AI は準備中」。押せない。

## 守ること

- 外部ライブラリ・外部フォント・外部の URL を使わない。`npm install` をしない。
- localStorage・IndexedDB・Cookie を使わない。
- `innerHTML` に、URL や `trace` 以外から来た文字を入れない。文字は `textContent` か、エスケープしてから入れる。
- モジュールの形は `js/geometry.js` と同じ。`board-view.js` と `app.js` は DOM を使ってよいが、Node で `require` しても例外にならないようにする（`document` がなければ何もしない）。
- 見た目はモックアップ第 3 案に合わせる。モックアップにない部品（鏡の像・レンズなど）は、同じペンの色と太さで描く。色は実装計画の Global Constraints の値。
- 変更しないファイル: `docs/mockups/`、`docs/superpowers/`、`tools/`、`CLAUDE.md`、`AGENTS.md`、`package.json`、`js/geometry.js`、Task 1 のファイル（上の `boards.js` の文を除く）。
- git の状態を変える操作をしない。
