# 実装指示書: レビュー（round 1）の指摘と、ブラウザで見つけた点の直し

## 目的

設計書 `docs/superpowers/specs/2026-11-21-ai-tutor-stage1-design.md` の 3 章「失敗の条件」（法則に合わない光線を 1 つも描かない）、6.1（見やすさの決まり）、7 章（不正なシーンは盤を描かず、文を出す）。
Codex のレビュー `.ai-review/20261121-224453_round1.md` の 3 件と、Claude Code がブラウザで見つけた 3 件を直す。

## 直すこと

### A. レンズのない場所で光線が曲がる（レビュー #1・High）

今: `lens-image` の代表の光線が、描かれたレンズの外（例: 物体 x=175 のとき (300, 410)）で曲がる。
決めたこと:
- レンズの大きさ（光が通れる範囲）を、シーンの値として 1 か所で決める（`js/config.js` に、レンズの半分の高さの暫定値を置く。暫定 150。光軸が y=210 なら 60〜360）。`board-view.js` が描くレンズの形と、`scene.js` の光線の計算は、同じ値を使う。
- 代表の光線のうち、レンズの面に当たる点がこの範囲の外になるものは、**描かない**（`rays` に入れない）。延長の破線も、その光線の分は入れない。
- 物体の高さはレンズの半分の高さより小さいので、「光軸に平行 → 焦点」と「中心を通って直進」の 2 本は必ず残る。像の位置は残った光線の交点と一致する（計算はうすいレンズの式のまま）。
- `lens`（平行な光）の盤でも同じ: 光源の高さは、平行な光がすべてレンズの範囲に入る所までしか動かせないようにする（端で止める）。
- 光線を省いたときは、`notes` に何も足さない（像の文はそのまま）。

### B. 垂直に近い入射で、反射角の数字が消える（レビュー #2・High）

今: 鏡を傾けて入射角・反射角が 0° 付近のとき、反射角の数字が `hidden: true` になる。
決めたこと:
- 置く順を「角度の数字 2 つ → つまみの文字 → 角度の名前 → 像の文字 → marks」にする。角度の数字は**決して隠さない**（候補がふさがっていても、`angleLabel` の位置に必ず描く）。
- 角度の名前がぶつかるときは、名前のほうを別の候補へ動かすか隠す（値と名前は盤の下の行にも出ている）。

### C. 不正なシーンを見せる途中で例外が出る（レビュー #3・Medium）

今: `elements = {}`・`elements = [null]`・屈折の盤で `options = null` などのとき、`validateScene` は拒むが、そのあとの `readout`・`controls` の参照が例外を投げ、画面が止まる。
決めたこと:
- `app.js` は、盤を出す前と描き直すたびに、まず `validateScene` を見る。直す所があれば、盤の場所に「この図は表示できません」と理由（`validateScene` の 1 件目）を出し、盤の下の値・切り替え・「ためしてみよう」の判定は行わない。「← ボード一覧」と「はじめの配置にもどす」は使える（「もどす」で正しい配置に戻る）。
- `boards.readout`・`boards.get(...).controls`（切り替えのラベルを作る所）・`boards.checkPrompt` は、形のおかしいシーン・`measures` を渡されても例外を投げず、`[]`（`checkPrompt` は false）を返す。

### D. 光線の矢印が小さくて見えない（ブラウザで確認）

今: 矢印が画面上で長さ 12px・幅 約 6px で、太さ 4.5px の光線の上ではほとんど見えない。
決めたこと: 矢印は画面上で長さ 16px・幅 13px（盤の幅 420px 未満では長さ 14px・幅 11px）。位置は今のまま（線分の 45%）。線分が画面上で 40px より短いときは付けない（今のまま）。

### E. 「法線」「鏡」などの文字が、光の当たる点に寄ってしまう（ブラウザで確認）

今: `placeLabels` に変えてから、`marks`（法線・鏡・焦点・光軸・空気・水・スクリーン）が、線の端ではなく交点の近くに置かれる。前（`trace` が返す `marks` の x・y にそのまま描く）のほうが読みやすかった。
決めたこと: `marks` は、**まず `trace` が返した位置そのもの**（文字の左下をその点に合わせる）を試す。そこが「盤からはみ出さない・先に置いた文字と重ならない・つまみの円と重ならない」を満たせば、そこに置く。だめなときだけ、今の候補（右・左・下・上…）を試す。つまみの文字と像の文字は今のまま。
- `placeLabels` の `labels` に、任意の項目 `preferOwn: true`（その位置そのものを最初の候補にする）を足して実現する。

### F. つまみを押したあとに、四角いオレンジの枠が出る（ブラウザで確認）

決めたこと: つまみの枠は、キーボードで選んだとき（`:focus-visible`）だけ出す。形は丸（つまみの円に `stroke` を付ける。四角い `outline` は使わない）。色は `#1A5CFF`、画面上で 3px。指やマウスで押しただけでは出さない。
