# 実装指示書: 動物のなかま分けで、合うなかまの数の文が古いまま残る

## 目的

`.ai-tasks/20261127-090000_bio1-unit.md` の盤 3（`bio-animals`）。Claude Code がブラウザで見つけた不具合を直す。

## 起きていること（ブラウザで確かめた）

1. `?board=bio-animals` を開き、「説明をとばして、すぐ動かす」を押す（はじめは えら・うろこ・卵生（殻なし）＝ 魚類）。
2. 切り替えを「肺」「羽毛」「卵生（殻あり）」の順に押す。
3. 盤の上の見出しは「あてはまるなかま: 鳥類」、輪はハト、盤の下の値も「鳥類」になる（正しい）。
4. しかし、盤の右の「合う特徴の数」の緑の行が **「魚類 3 つ（ぜんぶ）」のまま**。正しくは「鳥類 3 つ（ぜんぶ）」。

`js/picture.js` が返す文（key `count-match`）は正しいように見える（`match[1] + ' 3 つ（ぜんぶ）'`）。画面の層で、同じ key の文字の中身が、切り替えのあとに更新されていない疑いがある（推測。原因を調べて直す）。

## 決めたこと

- 切り替えのたびに、盤の中のすべての文字（`tags`・`texts`）・引き出し線・輪・画像が、今の `trace().picture` と同じ内容になる。key が同じでも、文・色・位置・折り返しを必ず更新する。前の状態の部品が残らない（数が減ったときは消える）。
- 同じ原因の不具合が、ほかの盤（`bio-flower`・`bio-plants`、光・音・力の盤の文字）にもないかを確かめ、あれば同じように直す。
