## 盤の中身（決めたこと）

### 共通

- 力の単位は N。100 g の物体にはたらく重力の大きさを 1 N とする。
- 浮動小数の計算結果をそのまま画面に出さない。値は整数（0.1 N 単位の整数 `forceTenths`、mm 単位の整数 `stretchMm` など）で持ち、文は整数から作る（「0.6 N」「3.0 cm」）。
- 単元の定義: `{ id: 'force', title: '中 1 力の世界', teacher: 'E', boards: ['force-spring', 'force-arrow', 'force-balance'] }`（音の後ろ）。

### ばねののび（`force-spring`）

- 名前「ばねののび」／問いかけ「おもりをふやすと、ばねはどれだけのびる？」／見出し「力の大きさとばねののびをしらべよう」
- 案内の文: 「ばねにおもりをつるして、力の大きさとばねののびの関係をしらべましょう。」
- シーン: `{ id: 'force-spring-basic', kind: 'force-spring', elements: [{ id: 'stand', type: 'stand' }, { id: 'spring', type: 'spring' }, { id: 'weights', type: 'weights' }], options: { weights: 3, spring: 'A' } }`
  - `options.weights` は 0〜5 の整数（数。文字列は不正）。`options.spring` は `'A'|'B'`。
- きまり: おもり 1 個 20 g ＝ 0.2 N。ばね A は 0.2 N で 1.0 cm、ばね B は 0.2 N で 2.0 cm のびる（のびは力に比例）。
- つまみはない。切り替え（`controls`）: 「おもりの数」0・1・2・3・4・5、「ばね」ばね A・ばね B。
- `measures = { weights, spring, forceTenths, stretchMm }`
- `readout`: 「力の大きさ 0.6 N」「ばねののび 3.0 cm」（おもり 0 個は「力の大きさ 0 N」「ばねののび 0 cm」）
- ためしてみよう:
  1. 「おもりを 5 個にして、ばねののびを 5.0 cm にしてみよう。」（ばね A で 5 個）
  2. 「ばね B に替えて、同じ力でののびをくらべよう。」（ばね B）
  3. 「ばね B で、のびを 4.0 cm にしてみよう。」（ばね B で 2 個）
- 盤の上の位置（600 × 420。`config.force.layout`）: 左にスタンドとばね。ばねの上のはし (150, 50)、何もつるさないときの長さ 100、のび 1 cm ＝ 12（いちばんのびて 10 cm ＝ 120）。おもりは 1 個の高さ 20 で下へ重ねる。右にグラフ: 原点 (330, 340)、横は 0.2 N ＝ 44（1.0 N で 550）、縦は 1 cm ＝ 22（10 cm で 120）。
- `trace().force`（音の `sound` と同じ考え方で、描く形はすべてエンジンが決める。光・音の盤では `force` は `null`、力の盤では `sound` は `null`）:
  `{ kind, stand: { lines: [[{x,y},{x,y}]…] }, spring: { points: [{x,y}…], top, bottom, naturalBottom }, weights: [{x,y,width,height}…], stretch: { from, to } | null（0 個のときは null）, forceArrow: { from, to } | null, graph: { origin, xEnd, yEnd, xTicks: [{x, text}…], yTicks: [{y, text}…], line: { from, to }, points: [{x,y,current}…（6 個）] }, labels }`
  - ばねの形（`spring.points`）は、のびに合わせて上下にのびる折れ線。巻きの数は変えない。
  - `graph.line` は今のばねの直線（原点から 1.0 N の点まで）。`points` は 0〜5 個の 6 点で、今の点に `current: true`。
- 文字（`labels`。`marks` にも入れる）: `spring`「ばね A」、`weights`「おもり 3 個」（0 個のときは「おもり なし」）、`stretch`「のび」、`force`「0.6 N」、`graph-x`「力の大きさ〔N〕」、`graph-y`「ばねののび〔cm〕」

### 力の表し方（`force-arrow`）

- 名前「力の表し方」／問いかけ「力は、矢印でどう表す？」／見出し「力を矢印で表そう」
- 案内の文: 「力は、作用点・向き・大きさを矢印で表します。矢印の先を動かして、いろいろな力を表しましょう。」
- シーン: `{ id: 'force-arrow-basic', kind: 'force-arrow', elements: [{ id: 'box', type: 'box' }, { id: 'force', type: 'force', newtons: 3, direction: 'right' }] }`
  - `newtons` は 1〜5 の整数。`direction` は `'up'|'down'|'left'|'right'`。
- 盤: 方眼 1 目もり 32（＝ 1 N）。箱の中心 ＝ 作用点 (300, 210)。矢印は作用点から、向きへ `32 × newtons`。
- つまみ: 矢印の先（`elementId: 'force', handle: 'tip'`、ラベル「力の矢印」）。指の位置と作用点の差で、横と縦の大きいほうを向きにし（同じなら今の向きのまま）、長さは近い整数（1〜5 ではしで止める）。作用点の真上（差が 0）は今のまま。
- キー（その 2 で使う。音の盤と同じ関数の形 `stepHandle` などに足す）: 今の向きと同じ向きのキーで +1 N、反対向きのキーで −1 N（1 N のときは変わらない）、直角の向きのキーで、大きさはそのままで向きだけ変える。
- `measures = { newtons, direction }`／`readout`: 「力の大きさ 3 N」「力の向き 右」（上・下・左・右）
- ためしてみよう: 「右向きに 5 N の力を、矢印で表そう。」「上向きに 2 N の力を、矢印で表そう。」「左向きに 4 N の力を、矢印で表そう。」
- `trace().force`: `{ kind, grid: { x, y, width, height, cell }, box: {x,y,width,height}, application: {x,y}, arrow: { from, to }, magnitude: { from, to }（矢印と平行で、矢印からはなした区切りの線）, labels }`
- 文字: `box`「箱」、`application`「作用点」、`direction`「力の向き」、`magnitude`「力の大きさ 3 N」、`scale`「1 目もり ＝ 1 N」

### 力のつり合い（`force-balance`）

- 名前「力のつり合い」／問いかけ「2 つの力がつり合うのは、どんなとき？」／見出し「2 つの力がつり合う条件をさがそう」
- 案内の文: 「厚紙を左右から引きます。力の大きさや力の線を変えて、2 つの力がつり合う条件をさがしましょう。」
- シーン: `{ id: 'force-balance-basic', kind: 'force-balance', elements: [{ id: 'card', type: 'card' }, { id: 'left', type: 'pull', side: 'left', newtons: 3 }, { id: 'right', type: 'pull', side: 'right', newtons: 3 }], options: { line: 'same' } }`
  - `newtons` は 1〜5 の整数。`options.line` は `'same'|'offset'`。`side` は left と right が 1 つずつ。
- 盤: 厚紙の中心 (300, 210)、1 辺 100。1 N ＝ 32。`same` のとき 2 つの力は高さ 210 の一直線上。`offset` のとき左の力は高さ 180、右の力は高さ 240（作用点は厚紙の左右の辺の上）。
- つまみ: 左の力の先・右の力の先（左右に動く。ラベル「左の力」「右の力」）。キーは、矢印がのびる向きで +1 N、反対で −1 N。
- 切り替え: 「2 つの力」一直線上・ずれている。
- 状態（`measures.state`）: `line` が `same` で大きさが等しい → `balanced`。`same` で右が大きい → `moves-right`、左が大きい → `moves-left`。`offset` → `turns`（大きさによらない）。
- `measures = { left, right, line, state }`
- `readout`: 「左の力 3 N」「右の力 3 N」と、状態の文「つり合っている」「つり合わない（右へ動く）」「つり合わない（左へ動く）」「つり合わない（回って動く）」
- 盤の上の文字 `state`: 「つり合っている（動かない）」「つり合わない（右へ動く）」「つり合わない（左へ動く）」「つり合わない（回って動く）」
- ためしてみよう:
  1. 「左右の力を両方 5 N にして、つり合わせてみよう。」（左 5・右 5・`balanced`）
  2. 「右の力を左の力より大きくして、厚紙が右へ動くのを見よう。」（`moves-right`）
  3. 「大きさが同じでも、力をずらすとつり合わないことをたしかめよう。」（左 ＝ 右 かつ `offset`）
- `trace().force`: `{ kind, grid, card: {x,y,width,height}, pulls: { left: { from, to }, right: { from, to } }, lines: [{ from, to }…]（力の線の破線。same は 1 本、offset は 2 本）, labels }`
- 文字: `card`「厚紙」、`left`「左の力 3 N」、`right`「右の力 3 N」、`state`（上の文）、`scale`「1 目もり ＝ 1 N」

## 変更・作成するファイル
