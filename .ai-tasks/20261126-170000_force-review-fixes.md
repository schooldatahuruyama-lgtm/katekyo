# 実装指示書: 力の単元の直し（レビュー round 1 と、ブラウザでの確認の指摘）

## 目的

Codex のレビュー `.ai-review/20261126-152236_round1.md` の 2 件と、Claude Code がブラウザで見つけた 3 件を直す。
見本: `docs/mockups/force-unit-mockup.html`。

## 直すこと

### 1. ばねの説明の最初の手で、ばねがもうのびている（High。レビュー #1）

今: 1 手目「何もつるさないときの長さを、おぼえておこう」で描かれるばねが、おもり 3 個分のびた形。

決めたこと:
- 説明中、`el:weights` の手より前は、ばねを**何もつるさないときの長さ**（下のはし ＝ `spring.naturalBottom`）で描く。
- `el:weights` の手で、おもりが現れるのに合わせて、ばねが今ののびた長さまでなめらかにのびる（その手の描く時間の中で。コマごとには属性だけを変える決まりを保つ）。その手が終わったあとは、のびた長さのまま。
- 何もつるさないときの形は、エンジンが返す（`trace().force.spring` に、何もつるさないときの折れ線の点 `naturalPoints` を足す。巻きの数は同じ）。画面の層で形を計算しない。のびる途中の形は、2 つの折れ線の同じ番号の点どうしを、進み具合で直線的にまぜたもの。
- 「もどる」で 1 手目にもどったとき・「とばす」・「動きをへらす」でも、その手に合う長さになる（1 手目は何もつるさないときの長さ、2 手目の終わりからはのびた長さ）。
- 自分で動かす状態（説明のあと・説明をとばしたあと）は今のまま。

### 2. せまい画面で、図の中の力の値「0.8 N」「1.0 N」が消える（High。レビュー #2）

今: 画面幅 319px（盤の幅は左右の余白を引いて 279px）で、ばね B・おもり 4 個／5 個のとき、置き場所がなく `force` の文字が出ない。

決めたこと: 盤の幅 279px 以上のすべての配置（おもり 6 × ばね 2）で、図の中の文字（`spring`・`weights`・`stretch`・`force`・グラフの軸の名前）を**どれも消さない**。置けないときは、ほかの置き場所の候補（おもりの左・右、スタンドの外など）を足すか、エンジンの置き場所の点を直す。文字 16px 以上・ほかの文字や図と重ならない・盤の中、の決まりは守る。
- テストは、画面幅ではなく**盤の幅**（279・335・700 など）で全配置を確かめる。今の 319px のテストは、盤の幅としての 279px も足す。

### 3. 力の矢印の先（矢じり）が、つまみにかくれて見えない（Claude Code の確認）

`force-arrow` と `force-balance`。力は矢印で表すので、矢じりが見えないと向きが分からない。

決めたこと: 矢じり（三角）を必ず描き、つまみにかくれないようにする。つまみ（白い丸）は、矢の先から矢印の向きへ少し先（つまみの半径 ＋ 矢じりが見える分）にずらして置く。つかむ範囲の中心はつまみの中心。つまみが盤の外に出ないこと（上向き 5 N など。出るときは、盤の上の配置（エンジンの `layout`）を直して収める）。
- 矢の先の位置 ＝ 力の大きさ（32 × N）は変えない（矢じりの先が、目もりの線の上に来る）。
- `force-spring` のばねを引く力の矢印にも矢じりを描く。

### 4. 「作用点」の文字が、作用点の点から遠い（Claude Code の確認）

今: `force-arrow` で、「作用点」が箱の左の外（点から 100 単位ほど）に出る。

決めたこと: 「作用点」の文字は、作用点の点から 60 単位以内に置く。箱の線・矢印・ほかの文字と重ねない。置けない向きがあるときは、点から文字へ細い引き出し線を引く。4 つの向き × 5 通りの大きさのすべてで。`force-balance` では作用点の文字は出さない（今のまま）。

### 5. ばねを引く力の矢印が、おもりに重なる（Claude Code の確認）

決めたこと: `force-spring` の力の矢印は、おもりの四角と重ねない。いちばん下のおもりの下のはしから下向きに描く（見本のとおり）。長さは力に比例（0.2 N ごとに同じ長さ）で、スタンドの台の線より上に収まる長さにする（おもり 5 個・ばね B でも）。値の文字は矢印の横。
