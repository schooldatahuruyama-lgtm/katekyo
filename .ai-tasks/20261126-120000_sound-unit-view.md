## 作るもの

### 読みこみ（`index.html`・`sw.js`）

- `index.html`: `js/sound.js`（`js/scene.js` より前）、`content/scripts-sound.js`（`content/scripts-light.js` より後ろ）、`content/voice-sound.js` を足す。
- `sw.js`: `VERSION` を上げる。`PRECACHE` に上の 3 つを足す。音声ファイル（mp3）は今と同じく別のキャッシュ（開いた盤の分だけ保存）。
- アプリの中での名前: 台本は `Hikari.scriptsSound`、音声の一覧は `Hikari.voiceDataSound`（`BASE` は `assets/audio/sound/`）。

### 画面（`js/app.js`）

- 盤の単元（`boards.list()` の `unit`）から、その単元の台本と音声の一覧をえらぶ（光 → `scripts`・`voiceData`、音 → `scriptsSound`・`voiceDataSound`）。固定の読みこみ先をなくす。
- ホーム: `boards.units()` を回し、単元ごとに見出し「中 1 光の世界 ― ボードをえらぶ」「中 1 音の世界 ― ボードをえらぶ」と盤の行を出す。案内の文は単元によらない文（設計書 3.1 節）。盤の名前の列は、音の盤の名前（「音の大きさと高さ」）が 1 行に収まる幅にする。幅 375px では横にはみ出さない。
- 操作の説明の文（設計書 3.2 節の「操作の説明」）を 3 盤ぶん足す。
- はじめの先生は `units()` の `teacher`（端末に覚えた先生があればそれ）。
- 読む時間: 音声を使わないとき、`explain.buildTimeline` に `readMs`（`explain.readMs(その先生の文)` の配列）を渡す。`tick` の次へ進む条件、「動きをへらす」の時間割にも入れる。音声を使うとき（音声が鳴っている手）は渡さない。
- 盤の下の値を出しはじめる手: `angle:` のある盤は今のまま。ない盤は、`label:` か `distance` のある最初の手から。どちらもない盤（`sound-string`）は最後の手から。
- 切り替えの `aria-label`: `thickness` は「弦の太さ」、`tension` は「弦の張り」。
- `sound-speed` は、盤のすぐ下に凡例「点線（‥‥）＝ 光（すぐに届く）／ 破線（－ －）＝ 音の波」を出す（見本のとおり。色だけで区別しない）。
- `doc.title` の「ひかりボード」は今のまま。

### 盤の描画（`js/board-view.js`、要るなら `js/view-math.js`・`css/app.css`）

`trace().sound` と `marks`・`rays`・`handles` だけを使って描く。**形を自分で計算しない**（点・弧・矢印はエンジンが返したものをそのまま使う）。

- `sound-wave`: おんさ、方眼（細い線）と横軸、波形（青のペン色）、振幅の矢印と破線、1 回の振動の区切り、文字（`labels`）。
- `sound-string`: 箱、弦（`thick` のときは太い線）、ことじ（三角の台）、弦のふるえ（`vibration` の両はしの間の、上下にふくらんだ薄い形。高さ `heightPx`）、方眼と波形、振幅の矢印、文字。
- `sound-speed`: 地面、花火（放射の線）、見る人（頭と体の簡単な形）、音の波（破線の弧）、光の線（`rays` の `dotted`）、距離の矢印、文字。
- 色は `config.colors` の今の色を使う（波・弧は `bluePen`、光は `ray`、補助の線は `normal`）。新しい色を足さない。
- 文字は今と同じく `viewMath.placeLabels` で置き、実表示で 16px 以上、つまみのつかむ範囲は半径 24px 以上（`viewMath.sizes()`）。文字どうし・文字とつまみ・文字と波形が重ならないようにする。盤の外に出ない。
- 説明中（描きながらの説明）: 今の作り（絵を 1 回だけ作り、コマごとには属性だけを変える）を保つ。波形は左から右へ描かれていく。弧は内側から順に現れる。重要語句（「」の用語と同じ文字。「振幅」「弦」など）は書かれていく出し方、ほかの文字はふわっと出る（今と同じ決まり）。ペンは線・弧・重要語句の先に付く。`point:` は今と同じ指す印。
- つまみに上下・左右の向きの印（↕・↔）を出す（見本のとおり。今のつまみに向きの印があるなら同じ形で）。

## 端の場合（決めたこと。それぞれテストを書く）

| 場合 | 扱い | テスト |
|---|---|---|
| `?board=sound-wave`・`sound-string`・`sound-speed` | その盤が開く | 模擬 DOM |
| 不正な `?board=`（知らない id、空、重複、長すぎる値） | 今と同じ。ホームと「指定された盤が見つかりませんでした」。値は画面に書き出さない | 今のテスト |
| 不正なシーン（数字の文字列、範囲外、きざみ外、部品の不足）を盤に渡す | 盤に「この図は表示できません」と最初の理由。値・切り替え・課題の判定を止める。例外を出さない | 模擬 DOM |
| つまみの取りうるすべての値（振動数 19 × 振幅 4、弦 4 通り × 長さ 11 × 強さ 4、距離 46） | 例外なく描ける。座標に `NaN` がない。文字が盤の中にあり、文字どうし・文字とつまみが重ならない | 模擬 DOM |
| 幅 375px・iPad の幅・パソコンの幅 | 文字 16px 以上、つまみ半径 24px 以上 | 模擬 DOM（今の決まりのテストを音の盤にも） |
| 100 Hz・振幅 1（2 つのつまみがいちばん近い） | それぞれつかめる。重なる所を押したら中心が近いほう | 模擬 DOM |
| 説明の全部の手 × 6 体 × 3 盤を 16ms きざみで進める | 例外なし。ペンの位置に `NaN` なし。最後の手のあと、自分で動かす状態の絵と同じものが出る | 模擬 DOM |
| 音声なし | 1 手は `max(描く時間, 読む時間) ÷ 速さ ＋ 間 ÷ 速さ` まで次へ進まない。「次へ」は待たずに進める。「止める」で待つ時間も止まる。0.5 倍・2 倍。光の盤でも同じ | 模擬 DOM |
| 音声あり | 今と同じ進み方（読む時間は入れない） | 今のテスト |
| 音声が読みこめない | 今と同じ黄色の帯。文字だけで進み、読む時間を当てる | 模擬 DOM |
| 光の盤で先生・音声・速さをえらんだあと、音の盤を開く | 覚えた設定がそのまま使われる。音の盤の音声は `assets/audio/sound/` から読む（光の音声を読まない） | 模擬 DOM |
| `index.html` が読むファイルが `PRECACHE` にない | テストが失敗する | offline |
| 光の 6 盤 | 見た目・動き・テストが今のまま（音声なしの読む時間だけが変わる） | 今のテスト |

違反や失敗の見せ方: 不正なシーンは盤に「この図は表示できません」と理由。音声の失敗は今と同じ黄色の帯。黙って別の値に直さない。
