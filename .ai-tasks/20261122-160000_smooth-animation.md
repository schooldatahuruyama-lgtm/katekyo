# 実装指示書: 描きながらの説明の動きを、なめらかにする

## 目的

設計書 `docs/superpowers/specs/2026-11-22-explain-animation-design.md` 2.3（描き方）。
ユーザーから「説明しているときの文字の出し方や図の動きが、すごくカクカクしている」と指摘があった。原因を直す。

## 原因（Claude Code が `js/board-view.js` を読んで確かめた）

1. 説明中、1 コマ（`requestAnimationFrame`）ごとに `draw()` が、`scene.trace`・`scene.handles`・`math.placeLabels` を計算し直し、`artRoot.replaceChildren()` と `labels.replaceChildren()` で SVG の中身を全部作り直している。
2. 手描き風のゆらぎの加工（`feTurbulence` + `feDisplacementMap` の filter）を、のびている途中の線にも掛けている。線が変わるたびに、加工の計算がやり直しになる。
3. 文字が 1 文字ずつ現れる（段々に出る）。
4. 線・弧の進み方が、時間に対してまっすぐ（緩急がない）。

## 直すこと

### 1. 説明中は、絵を 1 回だけ作り、コマごとには属性だけを変える

- 説明の状態（`setState` に null でないもの）を受け取っている間:
  - 絵の部品（SVG の要素）は、**全部描き終えた形で 1 回だけ作る**（`scene.trace`・`scene.handles`・`math.placeLabels`・`math.sizes` も、そのとき 1 回だけ）。作り直すのは、盤の表示幅が変わったとき・シーンが変わったとき・説明を始めたとき・説明を終えたとき（null を渡されたとき）だけ。
  - コマごと（`setState` が呼ばれるたび）には、各部品の「進み具合」に応じて、**属性だけ**を変える: 線の終点（または `stroke-dashoffset`）、弧の `d`、部品の `opacity` と `transform`、文字の現れ方（下の 3）、ペンの印の位置。要素を作らない・消さない。
  - 進み具合が前のコマと同じ部品は、属性を書きかえない（描き終わった部品を毎コマさわらない）。
- 進み具合 0 の部品は、`display: none`（または `visibility: hidden`）にしておく。
- 自分で動かす状態（null）のときの描き方と動きは、今のまま（つまみを動かすたびに描き直してよい）。

### 2. ゆらぎの加工は、描き終えた線にだけ掛ける

- 説明中、進み具合が 1 未満の線・弧には filter を付けない。1 になったら filter を付ける（今、filter を付けている種類の線だけ）。
- 自分で動かす状態では、今のまま。

### 3. 文字は、左から右へなめらかに現れる

- 盤の中の文字（`text`）は、1 文字ずつではなく、左から右へ連続して現れるようにする。
  - やり方: 文字ごとに `clipPath`（中に `rect`）を 1 回だけ作り、`rect` の幅を「文字の箱の幅 × 進み具合」にする。箱は `math.labelBox`（今ある見積もり）を使い、左右に 4 単位の余裕を持たせる。`text-anchor` が `end`・`middle` のときも、文字の左端から現れること。
  - 進み具合が 1 になったら `clip-path` を外す（文字のふち取りが切れないようにする）。
- ペンの印は、現れている所の右端に置く。
- 文字の位置・大きさ・ふち取りは変えない。

### 4. 進み方に緩急を付ける

- `js/view-math.js` に `ease(p) → number` を足す（0〜1 を受け取り、ゆっくり始まり・ゆっくり終わる値を返す。`p * p * (3 - 2 * p)`。0 未満は 0、1 より大きいは 1、NaN・数でないものは 0）。
- 線・弧・文字の現れ方には `ease` を通した値を使う。部品がふわっと現れる動き（大きさ 0.4 → 1、不透明度）は、終わりだけゆっくり（`1 - (1 - p) * (1 - p)`。`easeOut(p)` として足す）。
- 時間割（いつ始まり、いつ終わるか）は変えない。変わるのは、その間の進み方だけ。

### 5. 説明中、盤の外の画面も毎コマ書きかえない

- `js/app.js` の、コマごとに呼ばれる処理（`tick`）の中で、吹き出し・「ここまでの説明」・進み具合の印・ボタンの文字・盤の下の行を、**変わったときだけ**書きかえる（手が変わったとき、止める／再生、速さを変えたとき、など）。毎コマ `textContent` を入れ直したり、要素を作り直したりしない。
- 今そうなっているかを確かめ、なっていなければ直す。
