# 実装指示書: 音の単元の直し（レビュー round 1 と、ブラウザでの確認の指摘）

## 目的

設計書 `docs/superpowers/specs/2026-11-25-more-units-design.md` 3.2 節。
Codex のレビュー `.ai-review/20261126-120403_round1.md` の 1 件と、Claude Code がブラウザで見つけた 3 件を直す。

## 直すこと

### 1. 振動数をキーボードで 950 Hz にできない（High。レビュー #1）

今: キーで座標を 4 単位ずつ動かして近い値に丸めるので、900 Hz ⇔ 1000 Hz と飛ぶ。

決めたこと: 音の盤のつまみ（振幅・振動数・ことじ・はじく強さ・見る人）は、**矢印キー 1 回で、となりのきざみへ 1 つだけ動く**。
- 振動数: ← で 1 つ左の位置のきざみ（＝ 50 Hz 高い）、→ で 1 つ右（＝ 50 Hz 低い）。画面の上でつまみが動く向きとキーの向きを合わせる。
- 振幅・はじく強さ: ↑ で 1 つ大きく、↓ で 1 つ小さく。ことじ: → で長さ +5、← で −5。見る人: → で +34 m、← で −34 m。
- はしでは動かない（値はそのまま。例外を出さない）。動かない向きのキー（振幅のつまみで ←→ など）は何もしない。
- 光の盤のキー操作は変えない。

### 2. 弦の盤の切り替えに見出しがない（Claude Code の確認）

今: 「細い・太い」「弱い・強い」のボタンだけが並び、何の切り替えか画面で分からない（`aria-label` だけ）。

決めたこと: `sound-string` の切り替えは、それぞれの組の前に、目に見える見出し「弦の太さ」「弦の張り」を出す（見本 `docs/mockups/units-mockup.html` の 4 章のとおり）。えらんでいるものは、今の青の塗りに加えて「✓」を付ける（色だけで区別しない。見本のとおり）。光の盤（屈折）の切り替えの見た目は変えない。

### 3. 「おんさ（音源）」の文字に、おんさの柄がかかる（Claude Code の確認）

決めたこと: おんさの形（柄の下のはしまで）と「おんさ（音源）」の文字が重ならない。パソコンの幅・iPad の幅・幅 375px のどれでも。文字は盤の中に収める。

### 4. 「○.○ 秒後に聞こえる」の文字に、距離の矢印や光の線がかかる（Claude Code の確認）

決めたこと: `sound-speed` の時間の文字は、距離の矢印・光の線・見る人の形と重ならない所に置く。距離 46 通りすべてで。置けないときは見る人の反対側（右または左の上）へずらし、それでも盤の中に収める。
