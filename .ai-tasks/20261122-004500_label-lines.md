# 実装指示書: 文字が線をまたがないようにする（2 サイクル目 round 1 の指摘）

## 目的

設計書 `docs/superpowers/specs/2026-11-21-ai-tutor-stage1-design.md` 6.1（盤が縮んでも文字が線に重ならない）。
Codex のレビュー `.ai-review/20261121-232656_round1.md` の 1 件と、Claude Code が幅 375px のブラウザで見た 2 件を直す。

今の様子:
- 幅 319px の `lens-image` で、「光軸」が上の候補へ動き、箱が光軸（y=210）をまたぐ。`straight` の「スクリーン」は、盤の中へ寄せた結果、スクリーンの線（x=550）をまたぐ。（レビューの指摘）
- 幅 375px の `reflect` で、つまみの文字「かたむける」が鏡の線の上に出る。`lens-image` で右の「焦点」がスクリーンのつまみにかかる。（ブラウザで確認）

原因: `placeLabels` は、文字どうしとつまみの円しか見ていない。`markBox` で線を避けても、そのあとの「盤の中へ寄せる」「別の候補へ動かす」で線の上に戻ることがある。

## 直すこと

1. `view-math.placeLabels(labels, obstacles, sizes, lines)` に、4 つ目の引数 `lines: [{ x1, y1, x2, y2 }]`（文字を重ねたくない線分）を足す。省いたとき・配列でないときは `[]` として扱う（今までの呼び方はそのまま動く）。
2. 文字の箱が `lines` のどれかと交わる候補は使わない。これは、最初の候補（`preferOwn` の位置、盤の中へ寄せたあとの位置）にも、ほかのすべての候補にも当てはめる。箱と線分の交わりは、箱を画面上で 3px（`3 × unitPerPx`）ふくらませて判定する（線の太さの分）。
3. `board-view.js` は、`lines` に次の「面や軸の線」を渡す: 鏡、境界（水面）、法線、光軸、スクリーン、ついたて、レンズの中心の線（レンズの上の端から下の端まで）。**光線・延長の破線・角度の弧は入れない**（光線は動くたびに変わり、文字の置き場がなくなるため。光線との重なりは、ふち取りで読めるようにしてある）。
   - この一覧を作る所は、画面なしで呼べる関数にする（今の `labelData` と同じ場所に `lineData(scene, traceResult)` のような形で）。
4. 置けないとき:
   - `marks`（法線・鏡・焦点・光軸・スクリーン・ついたて・空気・水・ガラス）と角度の名前と像の文字は、今までどおり隠す。
   - つまみの文字（光源・かたむける・物体・スクリーン・焦点距離・ついたて・見る人）も隠す（つまみには `aria-label` があり、盤の下の行に操作の説明がある）。
   - 角度の数字は、今までどおり決して隠さない（線と交わっても `angleLabel` の位置に出す）。
5. 候補の数を増やす: 今の 8 方向に加えて、同じ 8 方向で相手からの距離を 2 倍にした 8 つも、あとに試す（せまい盤で置き場を見つけやすくするため）。
